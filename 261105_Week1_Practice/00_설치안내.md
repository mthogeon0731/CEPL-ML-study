## 2. Miniforge 설치

**왜 Anaconda 가 아니라 Miniforge 인가**: Anaconda 배포판과 그 기본 채널(defaults)은 직원 200명 이상 기관에서 쓰면 유료 라이선스가 필요하다. 연구소·회사가 여기에 해당한다. Miniforge 는 무료인 **conda-forge 채널만** 쓰므로 이 문제가 없다. 쓰는 명령(`conda …`)은 Anaconda 와 같다.
이미 Anaconda 가 깔려 있으면 지우지 않아도 되지만, 이 스터디 환경은 아래처럼 `-c conda-forge` 로만 만든다.

1. https://github.com/conda-forge/miniforge 의 Download 표에서 받는다
   - Windows: `Miniforge3-Windows-x86_64.exe`
   - Mac: Apple silicon 은 `Miniforge3-MacOSX-arm64`, Intel 은 `Miniforge3-MacOSX-x86_64`
2. 설치 중 **"Just Me"** 선택, 설치 경로는 기본값 그대로
   - ⚠️ Windows 사용자 이름이 **한글**이면 경로를 `C:\miniforge3` 처럼 영문 폴더로 바꾼다 (9절 참고)
3. "Add Miniforge3 to my PATH" 는 체크하지 않는다 (기본값). 대신 **Miniforge Prompt** 를 쓴다
4. 시작 메뉴 → **Miniforge Prompt** 실행. 맨 앞에 `(base)` 가 보이면 성공 (Mac 은 터미널을 새로 열면 `(base)` 가 보인다)

## 3. 스터디 환경 만들기

Miniforge Prompt 에 한 줄씩 붙여 넣는다.

```bash
conda create -n mlstudy -c conda-forge python=3.11 rdkit scikit-learn xgboost pandas matplotlib jupyter ipykernel -y
conda activate mlstudy
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install torch_geometric shap
```

- 첫 줄: `mlstudy` 라는 환경을 만들고 기본 패키지를 넣는다 (5–10분)
- 둘째 줄: 그 환경으로 들어간다. 맨 앞이 `(mlstudy)` 로 바뀐다. **앞으로 매번 이 줄부터 친다**
- 셋째 줄: PyTorch (CPU 판). GPU 가 없어도 이 스터디는 충분하다. Mac 은 `pip install torch` 만
- 넷째 줄: 그래프 신경망(PyG)과 4주차 설명 도구(shap)

**conda 와 pip 차이**: 둘 다 패키지 설치 도구다. RDKit 처럼 C++ 부품이 있는 것은 conda(conda-forge)가 안전하고, PyTorch Geometric 처럼 파이썬만으로 된 것은 pip 로 충분하다. 한 환경 안에서 둘을 섞어 써도 되지만, **conda 로 먼저 깔고 pip 를 나중에** 쓴다.

## 9. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `'conda'은(는) 내부 또는 외부 명령…이 아닙니다` | 일반 명령 프롬프트에서 실행 | 시작 메뉴의 **Miniforge Prompt** 사용 |
| 설치 중 이상한 경로 오류, `UnicodeDecodeError` | Windows 사용자 이름이 한글 → 경로에 한글 | Miniforge 를 `C:\miniforge3` 에 다시 설치. 실습 폴더도 한글 없는 경로 (`C:\study`) 에 둔다 |
| 설치 중 `defaults` 채널 · 라이선스 안내가 뜸 | Anaconda 의 기본 채널로 받으려 함 | 명령에 `-c conda-forge` 가 있는지 확인. Miniforge 는 기본이 conda-forge 라 보통 생기지 않는다 |
| `ModuleNotFoundError: No module named 'rdkit'` | `mlstudy` 환경이 아닌 곳에서 실행 | 맨 앞이 `(mlstudy)` 인지 확인. Jupyter 에서는 커널이 `mlstudy` 인지 확인 |
| Jupyter 에 `mlstudy` 커널이 안 보임 | 커널 등록 안 됨 | `conda activate mlstudy` 후 `python -m ipykernel install --user --name mlstudy` |
| `ModuleNotFoundError: No module named 'feature'` | 노트북을 실습 폴더 밖에서 열었음 | 실습 폴더로 `cd` 한 뒤 `jupyter notebook` |
| `pip install` 중 SSL · 인증서 오류 | 학교·기관 망의 보안 설정 | 휴대폰 핫스팟 등 다른 망에서 설치 |
| `conda create` 가 몇십 분째 멈춤 | 의존성 계산이 오래 걸림 | 기다리거나, `conda install -n base conda-libmamba-solver` 후 다시 |
| 노트북 셀이 `[*]` 로 계속 돌아감 | 계산 중 (GNN 학습은 몇 분) | 기다린다. 멈추려면 위 메뉴 Kernel → Interrupt |
