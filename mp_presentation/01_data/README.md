# 01 데이터 — "mp(녹는점)를 예측하는 모델": 데이터는 무엇인가

11쪽 단계: **SMILES 수집** (`load_data`) · 발표 0:00–0:30 · 슬라이드 S1

## ① 발표에서 답할 질문 — 답의 재료는 이미 이 폴더에 있다

1. 무엇을 예측하나 — 분자(SMILES) → 녹는점 [K]. 지도학습 **회귀** (8쪽: 물성 9종 모두 회귀). mp는 결정화·고체 취급 단계에 필요 (2쪽); logS ≈ 0.5 − 0.01(mp[°C] − 25) − logP 로 용해도와도 연결 (`data/README_data.md` §3).
2. 데이터는 어디서, 몇 개 — **Bradley Open Melting Point Dataset** (figshare 2014) → `data/mp.csv` **19,945개, K**. 원본 27,976행에서 중복 8,031건을 중앙값으로 병합, `donotuse` 제거 (`data/README_data.md` §1).
3. 분포는 어떤가 — `data_card.md`: 68 ~ 790 K, 중앙값 380 K, 평균 378.5 ± 92 K. 300–500 K에 75 %; **150 K 아래 1 %(189개), 600 K 위 0.5 %(97개)** → 끝 영역은 데이터가 적다 (24쪽 끝 영역 과적합의 조건).
4. 왜 어려운 물성인가 — 48쪽 "잡음 큼". `README_data.md`: 반복 측정 4,679종 중 **410종은 값 차이 ≥ 10 K, 86종은 ≥ 50 K** → 중앙값으로 합쳐도 이 잡음이 **오차 하한**. "결정 패킹은 분자 그래프로 잘 안 보인다." ([추가] 결정 성질 — `../README.md` 하단)
5. 분자는 어떤가 — MolWt 16 ~ 1,701 (중앙값 215), 무거운 원자 1 ~ 122, Murcko 골격 3,840개 (벤젠 골격 5,382개, 비고리 3,074개), 입체 표기 있는 분자 1,330개(그래프·지문은 입체를 안 봄 → 12쪽 "설명 못 하는 잡음"), 염 1개.
