## 2. XAI — 무엇을 보고 예측하나 (XGBoost + 기술자, 본 결과표 모델의 SHAP)

mean |SHAP| [K] = 그 기술자가 예측값을 평균 몇 K 움직였나. 방향 = 기술자 값↑일 때 예측↑(+)/↓(−), corr(value, SHAP)로 판정.

| 순위 | 기술자 | random: mean\|SHAP\| / corr | scaffold: mean\|SHAP\| / corr | 방향 | 화학 상식과 대조 (31쪽 "설명 검증") |
|---|---|---|---|---|---|
| 1 | **BertzCT** (분자 복잡도: 크기·분지·고리·헤테로원자 종합) | 19.2 / +0.83 | 17.8 / +0.62 | ↑ → mp ↑ | 크고 복잡할수록 분산력·접촉면 ↑ → 맞음. 단 "복잡도"는 크기와 강하게 상관 |
| 2 | **TPSA** (극성 표면적) | 15.9 / +0.83 | 17.4 / +0.73 | ↑ → mp ↑ | 극성 ↑ → 쌍극자·수소결합 ↑ → 격자 에너지 ↑ → **맞음** |
| 3 | **RingCount** | 9.8 / +0.95 | 16.6 / +0.85 | ↑ → mp ↑ | 고리 = 강직성 → 녹을 때 얻는 엔트로피 작음 → mp ↑ (ΔS_fus 작음) → **맞음**. scaffold에서 비중 ↑ |
| 4 | **NumHDonors** | 8.5 / +0.82 | 9.2 / +0.74 | ↑ → mp ↑ | 수소결합 공여체 → 결정 내 H-결합 네트워크 → **맞음** |
| 5 | NHOHCount (N–H, O–H 수) | 5.8 / +0.82 | 4.8 / +0.71 | ↑ → mp ↑ | NumHDonors와 같은 정보 → 기여가 **나뉘어** 들어감 (16쪽 상관) |
| 6 | **NumRotatableBonds** | 4.8 / −0.81 | 5.7 / −0.85 | ↑ → **mp ↓** | 유연한 사슬 → 결정 패킹 느슨, ΔS_fus 큼 → mp ↓ → **맞음** (상위 중 유일한 음의 방향) |
| 7 | FractionCSP3 (sp³ 탄소 비율) | 4.2 / −0.84 | 4.7 / −0.84 | ↑ → mp ↓ | 3D·유연한 지방족 ↑ = 평면 방향족 ↓ → mp ↓ → 맞음 |
| 8–10 | fr_bicyclic ↑, SMR_VSA10 ↑, FpDensityMorgan3 ↓ | 3.1 / 3.1 / 3.1 | 3.4 / 3.6 / 2.9 | | 두고리 ↑(강직), 분자당 지문 밀도 ↓(= 분자가 큼) |

- **두 분할에서 상위 7개가 같다** (순서만 조금 다름) → 모델이 보는 것이 분할에 따라 흔들리지 않음.
- RF `feature_importances_` 상위도 같은 집합: random BertzCT 0.33 > TPSA 0.10 > NumHDonors 0.07 > RingCount 0.06 > NHOHCount 0.03; scaffold TPSA 0.30 > BertzCT 0.15 > RingCount 0.08 > NumHDonors 0.05 (`rf_importance_Descriptor_*.csv`, 노트북 §9 선택 과제).
- 11-06 보조 분석(전체 19,945, 기술자 203)의 상위 5(RingCount, TPSA, BertzCT, NumHDonors, NumRotatableBonds↓)와 **같은 집합·같은 방향** → 표본 5,000과 전체가 같은 결론.
- **방향이 설명 안 되는 기술자는 상위 10 안에 없었다** = 31쪽 "설명 검증" 통과. 단 MolWt·HeavyAtomMolWt는 상위 20 끝(2.2 K)에만 → "크기"는 BertzCT·RingCount·FpDensity가 대신 가져감.

### 읽을 때 주의 ([추가])

SHAP는 **모델이 무엇을 보는가**이지 **자연이 그런가**가 아니다. 기술자끼리 상관이 크므로(16쪽) TPSA–NHOHCount–NumHDonors–NOCount처럼 같은 정보가 여러 칸에 나뉘어 들어간다. "BertzCT가 1위"는 "크기·복잡도와 상관된 무언가가 중요하다"로 읽는다. 또 SHAP가 맞아도 **대칭성**(Mirex, 쿼터페닐)처럼 기술자에 없는 정보는 설명에도 없다 — 틀린 분자 분석과 SHAP가 서로 보완.

### GNN에서는

GIN의 원자 기여(4주차)와 BGIN의 σ(22쪽: 데이터가 드문 곳일수록 σ 큼)는 다음 단계. 이번에는 "GIN이 작은 비고리 분자에서 크게 틀린다"는 후분석까지.

## 3. 31쪽 질문 — mp 팀에서는 정확도와 설명 중 무엇이 먼저인가

**스크리닝이면 정확도, 설계·데이터 정제면 설명.** mp는 (2쪽) 결정화·고체 취급 공정에서 "이 후보가 상온에서 고체인가, 몇 K에서 녹는가"를 거르는 데 쓰인다. 거르는 단계는 **순위와 구간**이 맞으면 되므로 정확도(MAE 30–38 K, 기준선의 41–50 %)가 먼저다. 반면 이번 후분석이 보여 준 대로 설명(SHAP 방향, 틀린 분자)은 (i) 모델이 화학적으로 말이 되는 것을 배웠는지 확인하고, (ii) **데이터 오류(끓는점·염 기록)를 찾아내며**, (iii) 다음 실험(대칭성·결정 정보가 필요하다)을 고르는 근거가 된다. → 결론: **정확도로 거르고, 설명으로 믿을 수 있는지 확인한다.**

## 4. 2주차에 무엇을 바꿀까 (49쪽 예고: readout, 층 수, 결합 특징)

> **주의 (49쪽 규칙, 2026-11-09 검토 후 추가)**: 위 후분석은 모두 **test 집합**(노트북 test 1,000 / GIN test 500)에서 했다. 따라서 아래 변경 후보는 "test를 보고 고른 설정"이 되지 않도록 **가설로만** 둔다. 2주차에는 (i) 같은 진단(작은 비고리 분자 오차, 구간별 잔차)을 **validate 500개**에서 다시 확인한 뒤 변경을 고르고, (ii) 변경 전·후 비교도 validate MAE로 결정하며, (iii) test는 마지막에 한 번만 본다.

후분석 → 변경 후보 (가설): (a) **readout `--pooling sum`** — mean pool이 분자 크기를 지우는 것이 GIN의 작은 분자 오차와 맞물림 (21쪽: GIN 논문 readout = sum); (b) `--conv GINE` — 결합 특징 16개(공액·회전 가능) 사용, 회전 가능 결합은 SHAP 6위; (c) `--max_n 0` 전체 19,945개 — GNN은 데이터가 적을수록 불리 (19쪽), learning curve 논리(23쪽)로 확인.

## 자가점검 답

- 가장 많이 틀린 분자 3개: Mirex(값 맞음, 모델 한계), 바이닐 뷰티레이트(끓점 기록 의심), 바이닐 아세테이트(GIN이 작은 분자를 388 K로).
- 오차 큰 영역 = 데이터 적은 영역: 550 K 이상 n ≤ 41(scaffold)에서 MAE 82 K vs 350–450 K n ≈ 470에서 29 K → 숫자로 확인.
- SHAP 맞는 것: TPSA·NumHDonors ↑, NumRotatableBonds ↓. 설명이 "없는" 것: 대칭성 — 기술자에 없어서 SHAP에도 없음.
- 31쪽: 거르기는 정확도, 믿기는 설명.
- 2주차 한 줄: mean → sum readout부터.
