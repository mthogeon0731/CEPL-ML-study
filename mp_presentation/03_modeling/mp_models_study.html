mp(녹는점) 예측 모델 7종 학습 노트

Ridge · kNN · SVR · Random Forest · XGBoost · MLP · GIN — 각 모델이 어떻게 학습하고, 왜 이 문제에 이 모델을 넣어야 했는지, 장단점과 정합성, 그리고 우리 결과가 그 판단을 지지했는지

이 노트의 틀

머신러닝은 "모델 이름을 외우는 것"이 아니라 문제 정의 → 데이터·표현 → 모델(가설) → 손실함수 → 최적화 → 일반화 → 평가 → 응용의 연결을 이해하는 것이다. 모든 모델 절은 같은 순서로 쓴다: ① 한 줄 직관 → ② 가정과 가설 함수(수식·shape) → ③ 손실과 학습 과정 → ④ 하이퍼파라미터의 영향 → ⑤ 노트북의 실제 설정 → ⑥ 장점·단점 → ⑦ mp에서의 정합성·당위성 → ⑧ 우리 결과와 해석 → ⑨ 흔한 실수·자가진단.

슬라이드 N쪽 1주차 강의자료에 있는 내용 (쪽 번호는 자료 기준). 추가 자료에 없는 일반 머신러닝·통계 지식, 또는 우리가 따로 계산·검증한 내용. 두 가지를 섞어 "자료에 있는 것처럼" 말하지 않는다.

1.3 손실함수와 평가지표는 왜 다른가 9, 23쪽

MSE = (1/m) Σi (yi − ŷi)2   [K2]   — 학습(최적화)에 쓰는 손실
MAE = (1/m) Σi |yi − ŷi|   [K]   — 보고 지표. 단위가 물성 단위와 같아 "평균 몇 K 틀렸나"로 읽힌다
RMSE = √MSE   [K] ≥ MAE.  차이가 크면 크게 틀린 분자 몇 개가 있다는 뜻
R2 = 1 − Σ(yi − ŷi)2 / Σ(yi − ȳ)2   — 1이면 완벽, 0이면 평균으로 찍은 것과 같음, 음수면 평균보다 못함 yi: 측정값, ŷi: 예측값, ȳ: test 평균, m: test 분자 수

추가 학습에 MSE를 쓰는 이유: 제곱은 어디서나 미분이 매끈해 경사하강·닫힌 해가 쉽고, 통계적으로는 "오차가 정규분포를 따른다"는 가정 아래 최대우도 추정과 같다. 그러나 큰 오차에 벌점을 제곱으로 주므로 이상치(값 오류)에 민감하다 — mp처럼 끓는점·염 값이 섞인 데이터에서는 MSE로 학습한 모델이 이상치 쪽으로 끌릴 수 있다. 보고는 MAE로 하는 이유는 사람이 읽기 쉽고 이상치에 덜 휘둘리기 때문이다. 둘을 혼동하는 것이 흔한 실수다(손실 ≠ 지표).

기준선(baseline) — "좋다/나쁘다"의 첫 기준 23쪽

train 평균 ȳtrain으로 모든 test 분자를 예측했을 때의 MAE. 이번 과제: random 72.5 K, scaffold 76.0 K (train.py 분할: 75.2 K). 모델 MAE / 기준선 MAE가 1 미만이어야 "무언가를 배웠다"고 말할 수 있고, 1을 넘는 칸은 평균만도 못한 것이다 — 우리 24칸 중 4칸이 그랬다.

1.4 분할과 일반화 10, 14쪽

random 80/20은 무작위로 나눈다. 비슷한 분자(같은 Murcko 골격)가 train과 test 양쪽에 들어가므로 성능이 좋게 나온다 — 우리 표본에서 test 분자의 79 %는 같은 골격이 train에 있었다. scaffold 80/20은 희귀한 골격부터 test로 보내 test 분자 1,000개가 전부 train에서 못 본 골격이 되게 한다(겹침 0). 새 분자를 스크리닝하는 실제 상황에 가깝다. 따라서 "scaffold − random" 차이는 새 골격으로 일반화하는 비용이고, 이 차이가 큰 모델일수록 본 적 있는 뼈대를 외운 것에 가깝다.

추가 일반화 오차는 편향(bias)·분산(variance)·잡음의 합으로 생각한다. 편향 = 모델이 너무 단순해 진짜 함수를 못 담는 데서 오는 오차(과소적합), 분산 = 데이터가 조금 달라지면 모델이 크게 달라지는 데서 오는 오차(과적합), 잡음 = 같은 입력에 다른 y가 나오는 데서 오는 오차로 어떤 모델도 못 줄인다. mp는 잡음 항이 크다(반복 측정 86종 ≥ 50 K). 그래서 "train 오차가 작고 test 오차가 크다"를 전부 과적합으로 읽으면 안 되고, 잡음 하한을 함께 생각해야 한다.

1.5 왜 어떤 모델은 StandardScaler가 필요하고 어떤 모델은 아닌가 16쪽

zij = (xij − μj) / σj   (μj, σj는 train에서만 계산, test에는 같은 값을 적용 — 그렇지 않으면 누수)

기술자는 MolWt(수백)·TPSA(수십)·FractionCSP3(0–1)처럼 값의 크기가 제각각이다. 거리·내적·기울기로 작동하는 모델(kNN의 거리, SVR의 커널 ‖x−x'‖, Ridge의 벌점 ‖w‖², MLP의 경사하강)은 큰 값의 특징이 결과를 지배하므로 표준화가 필요하다. 트리(RF, XGBoost)는 "xj < t인가?"라는 질문만 하므로 단조 변환에 불변 — 스케일링이 필요 없다. 노트북은 Ridge·kNN·SVR·MLP를 Pipeline(StandardScaler, 모델)로 묶어 train에만 fit되게 했다. 단, 같은 Pipeline이 0/1 지문에도 적용되었는데, 이것이 지문 결과를 크게 바꾼다(11절).

1.6 "튜닝 없음"의 뜻 37, 49쪽

하이퍼파라미터를 바꿔 가며 test 점수를 보고 고르면 test가 더 이상 "처음 보는 데이터"가 아니다(누수). 이번 과제는 모든 모델을 노트북의 기본 설정으로 한 번씩만 돌려 같은 조건의 공정한 기준선을 만든다. 튜닝이 필요하면 train 안에서 교차검증(cross_val_score)으로 한다. 따라서 아래의 모든 수치는 "그 모델이 낼 수 있는 최고"가 아니라 "기본 설정에서의 출발점"이다 — 모델 간 차이가 수 K라면 튜닝으로 뒤집힐 수 있지만, 수십 K(예: Morgan + kNN)라면 설정이 아니라 모델·표현의 궁합 문제다.

2. 왜 이 7개 모델인가 — 선택의 논리와 mp에 대한 당위성

2.1 강의의 논리: 단순한 모델부터 → 기준 점수 → 복잡한 모델이 그 점수를 넘는가 19쪽

모델 하나를 돌려 MAE 30 K를 얻어도 그것이 좋은지 알 수 없다. 기준선(평균)은 72 K, 가장 단순한 선형 모델은 35 K, 트리 앙상블은 30 K … 이렇게 사다리가 있어야 각 단계의 복잡도가 얼마를 벌어 주는지 읽힌다. 여섯 고전 모델은 이 사다리이고, GIN은 "구조를 직접 배우는 복잡한 모델이 사다리 꼭대기를 넘는가"를 묻는 질문이다. 2주차 이후의 모든 변경(readout, 층 수, 결합 특징, BGNN)은 이 표의 한 줄을 더하는 방식으로 평가된다.

2.2 표현과 모델의 궁합 15쪽

15쪽은 표현별로 맞는 모델을 짝지었다: 기술자(실수 ~217) → Ridge·RF·XGBoost·SVR / 지문(0·1 2048) → kNN·RF·XGBoost·MLP / 그래프 → GCN·GIN·BGIN. 노트북은 두 표현에 여섯 모델을 모두 돌려 이 짝이 실제로 맞는지 확인하게 했다. 그래서 24칸 표에는 "맞는 짝"과 "안 맞는 짝"이 함께 들어 있고, 안 맞는 칸(기준선 이하 4칸)이 오히려 많은 것을 가르쳐 준다.

2.3 추가 귀납 편향(inductive bias)이 서로 다른 모델들을 고른 것

모든 모델은 "세상이 이렇게 생겼을 것"이라는 가정(귀납 편향)을 갖고 데이터의 빈틈을 메운다. 일곱 모델은 서로 다른 가정을 대표한다. 어떤 가정이 mp와 맞는지는 돌려 보기 전에는 모른다 — 그래서 가정이 다른 모델을 골고루 넣는 것이 올바른 실험 설계다.

모델가정(귀납 편향)가설 공간의 모양mp에서 그 가정이 뜻하는 것
Ridgey는 특징의 가법적 선형 결합초평면 ŷ = wᵀx + b"기여도의 합"(기 기여법 전통). mp는 가법성이 약한 물성

2.4 mp라는 물성에 대한 당위성 — 돌리기 전에 알 수 있었던 것

  • 데이터 규모: 표본 5,000(전체 19,945). 수천 개의 표 형식 데이터에서는 트리 앙상블이 강하고, 신경망·GNN은 "1만 개 이상"에서 유리하다 19쪽. → XGBoost·RF가 유력, GIN은 경계 아래라는 가설이 선다.
  • 잡음 하한: 반복 측정 86종 ≥ 50 K. 어떤 모델도 넘지 못하는 하한이 있으므로, 모델 간 비교는 "하한 근처에서 누가 먼저 멈추나"가 된다. 가운데 영역(300–450 K)에서 세 모델이 27–32 K로 비슷했던 것이 그 증거다.
  • 물성의 성격 추가: 녹는점은 분자 하나가 아니라 결정(고체)의 성질이다. 격자 에너지(극성·수소결합·분산력)와 녹을 때의 엔트로피 증가(유연성·대칭성)가 결정한다. 2D 기술자는 극성·수소결합·강직성의 대리변수(TPSA, H-공여체 수, 고리 수, 회전 가능 결합 수)를 갖고 있어 이 물성에 비교적 잘 맞고, 지문은 부분구조의 유무만 담아 "전체 분자의 극성·크기" 요약에는 약하다. 그래프 신경망은 구조를 직접 배우지만 결정 패킹·대칭성은 역시 입력에 없다.
  • 해석의 필요 31쪽: 공정 스크리닝은 정확도가 먼저지만, 틀린 예측을 찾고 데이터 오류를 걸러내려면 설명이 필요하다. 계수(Ridge)·중요도(RF)·SHAP(XGBoost)이 있는 모델을 포함해야 하는 이유.

3. Ridge 회귀 — 특징의 가중합, L2로 계수 억제

① 한 줄 직관 19쪽

각 기술자에 가중치를 곱해 더한 값으로 mp를 맞춘다. 가장 단순한 기준선이며, 가중치가 너무 커지지 않도록 벌점(L2)을 준다.

② 가정과 가설 함수

ŷ = wTx + b = Σj=1..d wj xj + b x ∈ ℝd (표준화된 기술자 217개 또는 지문 2048비트), w ∈ ℝd 가중치, b 절편. 파라미터 수 = d + 1 (기술자 218개, 지문 2,049개)

가정: (i) mp는 특징들의 가법적 함수다 — 고리 하나가 올리는 양은 다른 특징과 무관하게 일정하다. (ii) 특징 간 상호작용과 곡선 관계는 없다(있으면 사람이 x²나 x1x2 같은 특징을 미리 만들어 넣어야 한다). 추가 통계적으로는 잔차가 평균 0·등분산의 정규분포라는 가정 아래 MSE 최소화가 최대우도 추정이 된다.

③ 손실함수와 학습 과정

J(w, b) = Σi (yi − wTxi − b)2 + λ ‖w‖22   (λ = alpha, 절편 b는 벌하지 않음)
∂J/∂w = 0  ⇒  w* = (XTX + λI)−1 XTy   (닫힌 해, normal equation의 정규화판) X ∈ ℝm×d (열 평균 0으로 중심화), XTX ∈ ℝd×d, I ∈ ℝd×d. λI를 더하면 XTX가 특이(상관 큰 열, d > m)여도 역행렬이 존재한다

학습 과정: (1) StandardScaler로 열마다 평균 0·분산 1 (train 통계) → (2) XTX + λI (217×217 또는 2048×2048)를 만들고 → (3) 선형방정식을 Cholesky 분해로 한 번에 푼다. 반복(epoch)이 없다. 그래서 0.04 s(기술자)·0.6 s(지문)에 끝났다. 추가 비용은 O(m d² + d³)로, d = 2048이면 d³ 항이 지배해 기술자보다 15배 느려진 것이 그 때문이다.

손계산 예 추가 — λ가 계수를 "줄이는" 방식

특징 하나, 중심화된 데이터에서 w* = Σxiyi / (Σxi² + λ). Σxiyi = 50, Σxi² = 10이면 λ = 0 → w = 5.0, λ = 1 → w = 4.55, λ = 10 → w = 2.5. 벌점이 커질수록 계수가 0 쪽으로 눌린다(shrinkage). 표준화 후 Σxi² ≈ m = 4,000이므로 λ = 1은 분모를 0.025 %만 키운다 — 이번 설정에서 정규화는 거의 작동하지 않았다. 그래서 지문(d = 2,048, 희소)에서 분산을 못 눌러 scaffold 96 K가 나온 것으로 해석할 수 있다.

④ 하이퍼파라미터 λ(alpha)의 영향

λ계수 크기편향 / 분산거동
0최소제곱 해 그대로편향 최소 / 분산 최대상관 큰 기술자 쌍(TPSA–NHOHCount)에 부호 반대의 큰 계수가 붙어 불안정 16쪽
↑0 쪽으로 수축(0이 되지는 않음)편향 ↑ / 분산 ↓과적합 완화, 너무 크면 과소적합(모든 예측이 평균 쪽)
→ ∞w → 0—ŷ → b = ȳ (기준선과 같아짐)

추가 L1(Lasso)은 계수를 정확히 0으로 만들어 특징 선택을 하지만, L2는 모든 계수를 조금씩 줄인다. 상관이 큰 기술자 묶음에서는 L2가 기여를 묶음 전체에 나눠 주어 더 안정적이다.

⑤ 노트북의 실제 설정

'Ridge': make_pipeline(StandardScaler(), Ridge(alpha=1.0)) # alpha=1.0, fit_intercept=True(기본), solver='auto' → 밀집 X·m > d 이면 cholesky

⑥ 장점과 단점

장점

  • 닫힌 해, 수 초 이내, 하이퍼파라미터 1개 — 가장 싼 기준선
  • 볼록(convex) 문제라 전역 최적해 보장, 결과가 재현됨
  • 계수 wj의 부호·크기로 "어느 기술자가 mp를 올리나"를 바로 읽음(표준화했으므로 크기 비교 가능)
  • 학습 범위 밖에서 추세를 유지 20쪽 — 큰 분자로 외삽할 때 트리처럼 평평해지지 않음

단점

  • 가법성·선형성 가정: 상호작용·포화·임계 거동을 못 담음
  • 상관 큰 특징에서 계수 해석이 흔들림(λ로 완화) 16쪽
  • 희소 0/1 지문 + 표준화 + 작은 λ → 희귀 비트에 큰 계수 → 새 골격에서 무너짐(우리 scaffold 96.2 K)
  • 이상치(값 오류)에 MSE가 민감

⑦ mp에서의 정합성·당위성

왜 넣어야 했나. 첫째, 회귀 문제의 가장 단순한 가설이므로 "복잡한 모델이 벌어 주는 양"을 재는 자(尺)다. XGBoost 30.0 K와 Ridge 35.4 K의 차이 5.4 K가 바로 "비선형·상호작용이 mp에 기여하는 크기"다. 둘째, 추가 물성 예측의 전통인 기 기여법(group contribution)이 사실상 선형 가법 모델이다 — 분자를 작용기로 쪼개 기여를 더한다. Ridge는 그 전통을 기술자 공간에서 재현한 것이고, 이 모델이 기준선의 절반(35 K)까지 내려간다는 것은 mp의 상당 부분이 "크기·극성·수소결합의 가법적 합"으로 설명된다는 뜻이다. 셋째, 계수 해석으로 모델이 화학적으로 말이 되는 것을 배우는지 확인할 수 있다 31쪽.

맞지 않는 점. 녹는점은 가법성이 약한 대표적 물성이다 추가: 같은 작용기라도 대칭적으로 배치되면 패킹이 좋아져 mp가 크게 오르고(쿼터페닐), 유연한 사슬이 끼면 내려간다. 이런 "배치 의존"은 가법 모델 밖에 있다. 그래서 Ridge는 출발점이지 종착점일 수 없다.

⑧ 우리 결과

기술자: random 35.4 K (R² 0.74) / scaffold 45.1 K (R² 0.37) — 기준선의 49 % / 59 %. 6모델 중 4위. 기대(“조금 나은 정도”)보다 좋았다.
Morgan 지문: random 61.0 K (R² 0.23) / scaffold 96.2 K ✗ (R² −1.81, 기준선 76.0보다 나쁨). random→scaffold +35 K.
해석: 기술자에서는 "크기·극성의 가법적 합"이 꽤 맞지만, 지문에서는 표준화된 희귀 비트 2,048개 위에 사실상 정규화 없는 최소제곱을 한 꼴이 되어 본 골격을 외우고 새 골격에서 무너졌다(11절). 24쪽의 logP 예(Ridge + Morgan scaffold가 기준선보다 나쁨)와 같은 모양이다.

⑨ 흔한 실수·자가진단

  • 표준화를 test에 다시 fit하거나(누수), 절편에도 벌점을 주는 실수. 노트북은 Pipeline으로 둘 다 피했다.
  • "Ridge는 선형이라 약하다"로 끝내지 말 것 — 기술자 Ridge가 지문 XGBoost(39.5)보다 좋았다. 모델보다 표현이 먼저다.

자가진단

  1. w* = (XᵀX + λI)⁻¹Xᵀy에서 각 행렬의 shape를 d = 217, m = 4,000으로 써 보라. λI가 없을 때 역행렬이 존재하지 않을 수 있는 두 가지 상황은?
  2. λ를 2배로 하면 계수·편향·분산·train MAE·test MAE는 각각 어느 방향으로 움직이는가?
  3. 지문 + Ridge가 scaffold에서 기준선보다 나빠진 이유를 "표준화 · 희귀 비트 · λ = 1"의 세 단어로 설명하라.

4. kNN 회귀 — 가장 비슷한 분자 k개의 평균

① 한 줄 직관 19쪽

새 분자가 오면 train에서 가장 가까운 분자 k개를 찾아 그들의 mp를 (거리 가중) 평균한다. "비슷한 구조는 비슷한 물성"이라는 QSPR의 원리를 그대로 모델로 만든 것.

② 가정과 가설 함수

ŷ(x) = Σi∈Nk(x) wi yi / Σi∈Nk(x) wi,    wi = 1 / d(x, xi)  (weights='distance')
d(x, x') = ‖x − x'‖2 = √Σj(xj − x'j)2   (유클리드; 표준화된 특징 공간) Nk(x): x에 가장 가까운 train 분자 k개의 집합. k = 5. 파라미터는 "train 데이터 자체"(비모수, 메모리 기반)

가정: (i) 특징 공간에서 가까우면 y도 가깝다(국소 평활성). (ii) 거리 함수가 "화학적 비슷함"을 제대로 잰다 — 이것이 kNN의 전부이자 약점이다. 거리가 틀리면 아무리 k를 바꿔도 소용없다.

③ 손실함수와 학습 과정

명시적 손실 최소화가 없다. 학습 = train 데이터를 저장(0.06 s), 예측 = 거리 계산. 예측 비용은 분자당 O(m·d)로, 데이터가 커질수록 예측이 느려지는 유일한 모델이다. 추가 통계적으로는 k가 커질수록 평균을 많이 취해 분산이 줄고 편향이 늘며(k = m이면 기준선), k = 1이면 train 오차 0·분산 최대다. 거리 가중은 가까운 이웃에 더 큰 발언권을 주어 k가 커도 국소성을 유지하게 한다.

손계산 예 추가

이웃 3개의 (거리, mp) = (1, 380), (2, 420), (4, 300). 가중치 1/d = 1, 0.5, 0.25 → ŷ = (380·1 + 420·0.5 + 300·0.25) / 1.75 = (380 + 210 + 75) / 1.75 = 380 K. 단순 평균이면 366.7 K. 가까운 이웃(380)이 결과를 끌어당긴다.

④ 하이퍼파라미터의 영향

k ↑경계가 매끄러워짐, 분산 ↓ 편향 ↑; k = m이면 기준선
weights'uniform' = 단순 평균 / 'distance' = 가까운 이웃 우대(거리 0이면 그 이웃만)
거리 함수유클리드(연속 특징용) vs Tanimoto(0/1 지문용) 17쪽. 노트북은 두 표현 모두 표준화 유클리드 — 지문에는 맞지 않는 선택이었다(⑧)
특징 스케일표준화 안 하면 MolWt가 거리를 독점; 표준화하면(연속 특징) 공평해지지만, 0/1 비트에서는 희귀 비트가 거리를 독점(11절)

⑤ 노트북의 실제 설정

'kNN': make_pipeline(StandardScaler(), KNeighborsRegressor(n_neighbors=5, weights='distance')) # metric='minkowski', p=2 (유클리드). 지문에도 같은 Pipeline → 0/1 비트가 표준화됨

⑥ 장점과 단점

장점

  • 가정이 거의 없음(비모수) — 함수 모양을 몰라도 됨
  • 학습이 즉시, 새 데이터 추가가 쉬움(저장만)
  • 예측 근거가 "이 이웃 5개"로 보여서 설명이 직관적
  • 데이터가 조밀한 영역(300–450 K)에서는 강함

단점

  • 거리 함수·스케일에 전적으로 의존; 고차원(2048)에서 거리가 무의미해짐(차원의 저주)
  • 외삽 불가: 학습 범위 밖에서 평평 20쪽
  • 새 골격(scaffold)에서는 "가까운 이웃"이 사실상 없음 → 우리 +13 K(기술자), +40 K(지문)
  • 예측 비용 O(m·d), 메모리 = 데이터 전체

⑦ mp에서의 정합성·당위성

왜 넣어야 했나. 화학자가 머릿속으로 하는 추정("이 분자는 저 분자와 비슷하니 mp도 비슷하겠지")을 그대로 수식으로 옮긴 모델이므로, 유사 구조 원리가 mp에 얼마나 통하는지를 재는 실험이다. 또 가장 "외우는" 모델이라 random vs scaffold 차이가 "본 골격을 외운 효과"의 상한을 보여 준다 14쪽.

맞지 않는 점. mp는 작은 구조 변화(메틸기 위치, 대칭성)에 수십 K씩 뛰는 물성이라 "가까우면 비슷하다"는 가정이 자주 깨진다(activity cliff의 물성판). 그리고 노트북의 거리(표준화 유클리드)는 지문에 맞지 않았다 — 지문의 올바른 거리는 Tanimoto다 17쪽.

⑧ 우리 결과

기술자: random 38.5 K (6위) / scaffold 51.7 K — 기대대로 "비슷한 분자가 많은 영역 강함, 새 골격 약함"(+13 K).
Morgan 지문: random 86.2 K ✗ / scaffold 125.9 K ✗ — random에서도 기준선(72.5)보다 나쁜 유일한 칸.

추가 검증 왜 이렇게 무너졌는지 직접 재 봤다(표본 5,000, random 분할, test 300개). 표준화된 지문에서 두 분자 사이 제곱 거리의 76 %가 빈도 1 % 미만의 희귀 비트에서 나왔다. 그 결과 test 분자(무거운 원자 평균 16.1개)의 "가장 가까운 이웃 5개"는 평균 10.3개짜리 훨씬 작은 분자들이었다 — 희귀 비트가 적은 분자가 모든 분자의 이웃이 된다. 같은 300개를 Tanimoto 유사도로 이웃을 고르면(단순 평균) MAE 49.8 K, 표준화 유클리드는 92.4 K(기준선 73.6). 즉 kNN이 틀린 것이 아니라 거리가 틀렸다.

⑨ 흔한 실수·자가진단

  • kNN의 k(이웃 수)와 K-means의 K(군집 수)를 혼동. kNN은 지도학습 회귀/분류, K-means는 비지도 군집.
  • "지문에는 어떤 거리든 되겠지" — 0/1 벡터에 표준화 + 유클리드를 쓰면 희귀 비트가 거리를 독점한다.

자가진단

  1. k를 1 → 5 → 50으로 늘리면 train MAE와 test MAE는 어떻게 변하는가? k = 4,000이면?
  2. 표준화된 0/1 비트 j에서, 한 분자에만 그 비트가 켜져 있을 때 제곱 거리 기여는 1/(pj(1−pj))이다. pj = 0.5와 0.001의 기여를 비교하라.
  3. Tanimoto 유사도 |A∩B| / |A∪B|가 유클리드 거리와 달리 "둘 다 0인 비트"를 무시하는 이유는 무엇이고, 그것이 왜 지문에 맞는가?

5. SVR — 커널로 비선형, ε 밖의 오차만 벌점

① 한 줄 직관 19쪽

예측값 주변에 폭 ε의 "튜브"를 두고, 튜브 안에 들어온 점은 오차로 치지 않는다. 튜브 밖의 점(서포트 벡터)만이 모델을 결정하며, 커널(RBF)로 비선형 관계를 잡는다.

② 가정과 가설 함수

ŷ(x) = Σi∈SV (αi − αi*) K(xi, x) + b,    K(x, x') = exp(−γ ‖x − x'‖2)  (RBF) SV = 서포트 벡터(튜브 밖 또는 경계의 train 분자), αi, αi* ∈ [0, C] 쌍대 변수, γ = 1/(d · Var(X)) ('scale'; 표준화 후 ≈ 1/d = 1/217 또는 1/2048)

가정: y는 입력 공간에서 매끄럽게 변하는 함수(RBF 커널 = "가까운 점끼리 비슷하다"를 거리의 가우시안으로 표현). 추가 커널 트릭: 특징을 무한차원 공간으로 보내 선형 회귀를 하는 것과 같지만, 내적 K(x, x')만 계산하면 되어 그 공간을 실제로 만들 필요가 없다.

③ 손실함수와 학습 과정

minw,b,ξ   ½‖w‖2 + C Σi (ξi + ξi*)    s.t.  |yi − ŷi| ≤ ε + ξi(또는 ξi*), ξ ≥ 0
ε-둔감 손실:  Lε(r) = max(0, |r| − ε)   (r = 잔차; |r| ≤ ε이면 0) C: 튜브 밖 오차의 벌점 세기(크면 train에 맞추려 함), ε: 튜브 반폭 [K], ξ: 튜브를 벗어난 양(slack)

학습 과정: (1) 표준화 → (2) 위 문제의 쌍대(dual) 이차계획법을 libsvm의 SMO 알고리즘으로 푼다(α 두 개씩 골라 갱신) → (3) α ≠ 0인 점만 저장(서포트 벡터). 추가 커널 행렬이 m×m(4,000×4,000)이라 비용이 O(m²)–O(m³)로 자라며, 전체 19,945개면 노트북 설명대로 느려진다. 볼록 문제이므로 전역 최적해가 보장된다.

④ 하이퍼파라미터의 영향

C ↑오차 벌점 ↑ → 튜브 밖 점을 더 맞추려 함 → 복잡·과적합 쪽 (C ↓: 평평·과소적합)
ε ↑튜브가 넓어져 서포트 벡터 ↓, 모델 단순·둔감 (잡음 수준에 맞추는 것이 이상). ε = 0.1 K는 mp 잡음(수십 K)에 비해 매우 작아 거의 모든 점이 서포트 벡터가 됨
γ ↑커널이 좁아짐 → 각 점 주변만 영향 → 과적합(γ ↓: 넓고 평평). 'scale'은 특징 수로 정규화

⑤ 노트북의 실제 설정

'SVR': make_pipeline(StandardScaler(), SVR(C=10, epsilon=0.1)) # kernel='rbf', gamma='scale' = 1/(n_features·Var(X)) ≈ 1/d, epsilon 단위 = y 단위(K)

⑥ 장점과 단점

장점

  • 비선형을 커널 하나로, 볼록 최적화로 전역해
  • ε-둔감 손실은 작은 잡음을 무시 → 잡음 큰 y에 개념적으로 적합
  • 고차원에서도 안정(‖w‖² 정규화 내장)
  • 수천 개 규모에서는 빠름(기술자 2.2 s)

단점

  • O(m²)~O(m³): 수만 개부터 느려짐(지문 14 s, 전체 데이터면 분 단위)
  • C, ε, γ 세 개가 결과를 크게 좌우 — 튜닝 없이는 잠재력을 못 봄
  • 해석 불가(어느 특징이 왜인지 안 보임)
  • 데이터에서 멀어지면 K → 0 → 예측이 b(상수)로 수렴 추가 (20쪽은 "임의"로 분류)

⑦ mp에서의 정합성·당위성

왜 넣어야 했나. 선형(Ridge)과 트리 사이의 "매끄러운 비선형" 가설을 대표한다. 또 ε-둔감 손실은 측정 잡음이 큰 물성에 이론적으로 가장 잘 맞는 손실이다 — 잡음 폭 안의 오차는 맞추려 들지 않는 것이 옳기 때문이다. 데이터가 수천 개인 지금은 비용도 감당된다.

맞지 않는 점. ε = 0.1 K는 mp 잡음(수십 K)에 비해 사실상 0이어서 그 장점이 발휘되지 않았다(튜닝 없음 규칙 때문에 그대로 둠). 지문에서는 표준화된 희소 비트 때문에 거의 모든 쌍의 거리가 멀어 K ≈ 0, 예측이 상수 쪽으로 눌린다 — random과 scaffold가 54.8 / 55.5 K로 같이 나쁜(둘 다 평평한) 이유다.

⑧ 우리 결과

기술자: random 35.4 K (R² 0.70; Ridge와 같은 MAE지만 RMSE 50.2로 더 큼 → 큰 오차 몇 개) / scaffold 44.0 K (R² 0.38). 3위권.
Morgan: random 54.8 / scaffold 55.5 K — 12쌍 중 유일하게 random ≈ scaffold(+0.7 K). 외운 것도 없고 배운 것도 적은 "평평한" 모델의 신호.

⑨ 흔한 실수·자가진단

  • ε의 단위를 잊는 것 — y 단위(K)다. logP(단위 ~1)에서 0.1은 의미 있지만 mp(수백 K)에서 0.1은 0과 같다.
  • SVR을 분류기 SVM과 섞어 "마진 최대화"로만 설명하는 것 — 회귀에서는 튜브 폭과 ‖w‖²의 trade-off다.

자가진단

  1. γ를 10배로 키우면 커널의 폭, 서포트 벡터 수, train/test 오차는 어떻게 변하는가?
  2. ε를 mp의 잡음 수준(예: 10 K)으로 올리면 어떤 점들이 서포트 벡터에서 빠지는가? 그것이 왜 바람직할 수 있는가?
  3. 왜 SVR + Morgan은 random과 scaffold 점수가 거의 같았는가? 그 모델의 parity plot은 어떤 모양일지 그려 보라.

6. Random Forest — 깊은 나무 여러 개의 평균(배깅)

① 한 줄 직관 19쪽

데이터를 "TPSA < 48인가?" 같은 질문으로 계속 쪼개 잎마다 평균 mp를 저장하는 결정 나무를, 서로 다른 부트스트랩 표본으로 300그루 키워 평균한다. 나무 하나는 과적합하지만 평균은 안정적이다.

② 가정과 가설 함수

나무 하나:  T(x) = Σ잎 ℓ cℓ · 𝟙[x ∈ Rℓ],   cℓ = 잎 ℓ에 속한 train 분자의 mp 평균
숲:  ŷ(x) = (1/B) Σb=1..B Tb(x),   B = 300 Rℓ: 축에 평행한 직사각형 영역(xj < t 질문들의 교집합). 함수는 조각별 상수(계단)이며, 학습 범위 밖에서는 가장자리 잎의 값으로 평평하다

가정: y는 특징 축에 평행한 경계로 나뉘는 영역별 상수로 근사할 수 있다. 특징의 단위·스케일·단조 변환에 무관하다(분할 질문만 하므로).

③ 손실함수와 학습 과정

분할 기준(회귀):  영역 R을 (xj < t)로 둘로 나눌 때  Σi∈Rleft(yi − ȳleft)2 + Σi∈Rright(yi − ȳright)2 가 최소가 되는 (j, t)를 고른다 (= MSE 감소 최대)

학습 과정(나무 b마다): (1) train 4,000개에서 복원 추출로 4,000개 뽑기(부트스트랩; 약 63 %가 고유, 나머지는 OOB) → (2) 뿌리에서 모든 특징·모든 분할점을 훑어 MSE 감소가 최대인 질문 선택 → (3) 잎에 분자 1개가 남을 때까지(min_samples_leaf=1) 재귀 → (4) 300그루 독립 학습(병렬) → 예측은 평균. 추가 회귀 숲의 sklearn 기본은 max_features=1.0(모든 특징 고려)이므로 이번 모델은 "순수 배깅"이고, 나무 간 상관을 더 낮추려면 max_features를 줄이는 것이 보통이다. 비용 O(B · m log m · d) → 지문(d = 2048)에서 58 s로 가장 느린 모델이 되었다.

왜 평균하면 좋아지는가 추가

나무 B개의 예측이 각각 분산 σ², 서로 상관 ρ라면 평균의 분산은 ρσ² + (1−ρ)σ²/B. B를 키우면 두 번째 항은 0으로 가지만 첫 항 ρσ²는 남는다 — 그래서 부트스트랩(데이터를 다르게)과 특징 무작위화(질문을 다르게)로 ρ를 낮추는 것이 핵심이다. 편향은 깊은 나무라 낮고, 분산은 평균으로 낮춘다: 튜닝 없이도 안정적인 이유.

④ 하이퍼파라미터의 영향

n_estimators ↑분산 ↓(수렴), 시간 ∝ B. 300이면 충분히 수렴
max_depth / min_samples_leaf얕게·잎 크게 → 편향 ↑ 분산 ↓. 기본(제한 없음)은 과적합한 나무를 평균으로 보정하는 전략
max_features ↓나무 간 상관 ↓ → 평균의 분산 ↓, 단 너무 작으면 좋은 특징을 못 봄
bootstrap끄면 모든 나무가 같은 데이터 → 다양성 사라짐

⑤ 노트북의 실제 설정

'RandomForest': RandomForestRegressor(n_estimators=300, n_jobs=-1, random_state=SEED) # max_features=1.0(회귀 기본, 모든 특징), max_depth=None, min_samples_leaf=1, bootstrap=True. 스케일러 없음

⑥ 장점과 단점

장점

  • 튜닝 없이 안정 — 기본값으로 2위(기술자 33.5 K)
  • 스케일링·단조 변환 불필요, 이상치에 비교적 둔감(잎 평균)
  • 비선형·상호작용을 자동으로 잡음
  • feature_importances_로 해석(우리: BertzCT, TPSA, NumHDonors, RingCount …)
  • OOB 오차로 별도 검증 없이 일반화 추정 가능 추가

단점

  • 외삽 불가: 학습 범위 밖은 평평 20쪽 → 고융점 끝(> 550 K)에서 과소 예측
  • 조각별 상수라 매끄러운 추세를 계단으로 근사 → 작은 데이터에서 거침
  • 나무 300그루 저장·예측 비용, 고차원 지문에서 학습 느림(58 s)
  • 불순도 기반 중요도는 상관 큰 특징 사이에서 나뉘고, 범주가 많은 특징을 과대평가 추가

⑦ mp에서의 정합성·당위성

왜 넣어야 했나. 기술자 217개는 전형적인 표 형식(tabular) 데이터이고, 수천 행의 표 데이터에서 트리 앙상블은 가장 신뢰할 수 있는 비선형 기준선이다 19쪽. 스케일링·분포 가정이 없어 "모델을 잘못 설정해서 나쁜" 가능성이 가장 낮다 — 즉 데이터 자체가 얼마나 예측 가능한지를 재는 데 적합하다. 또 중요도로 모델이 보는 것을 확인할 수 있다(31쪽 설명 검증).

맞지 않는 점. mp 분포의 양 끝(< 200 K, > 550 K)은 데이터가 2–4 %뿐이고, 트리는 그 밖으로 외삽하지 못한다. Mirex(758 K)를 436 K로 예측한 것은 트리 모델의 구조적 한계다 — "가장 높은 잎의 평균" 이상을 낼 수 없다.

⑧ 우리 결과

기술자: random 33.5 K (R² 0.76, 2위) / scaffold 40.7 K (R² 0.49, 2위). 새 골격 비용 +7.2 K로 XGBoost와 함께 가장 작음.
Morgan: random 40.9 / scaffold 55.5 K — 지문에서도 살아남은 두 모델 중 하나(트리는 비트를 "있다/없다"로만 보므로 표준화 문제를 피함).
중요도 상위(random): BertzCT 0.33, TPSA 0.10, NumHDonors 0.07, RingCount 0.06, NHOHCount 0.03 — SHAP 상위와 같은 집합.

⑨ 흔한 실수·자가진단

  • "나무가 많을수록 과적합"이 아니다 — B를 키워도 분산만 줄 뿐 과적합이 늘지 않는다(부스팅과 다른 점).
  • 중요도를 인과로 읽는 것 — "BertzCT가 중요"는 "크기·복잡도와 상관된 무언가가 중요"다.

자가진단

  1. 부트스트랩 표본에 한 분자가 한 번도 안 뽑힐 확률 (1 − 1/m)m ≈ e−1 ≈ 0.37임을 설명하고, OOB 평가가 무엇인지 말하라.
  2. RF가 train에 없는 900 K짜리 분자를 받으면 예측은 무엇에 의해 결정되는가? Ridge라면?
  3. RF와 XGBoost 모두 "나무의 합"인데, 왜 하나는 분산을 줄이고 하나는 편향을 줄인다고 하는가?

7. XGBoost — 앞 나무의 오차를 다음 나무가 보정(그래디언트 부스팅)

① 한 줄 직관 19쪽

처음엔 평균으로 예측하고, 그 잔차(틀린 양)를 작은 나무가 배우고, 그 나무의 예측을 학습률만큼만 더한다. 이것을 600번 반복해 오차를 조금씩 깎아 나간다.

② 가정과 가설 함수

ŷi = Σk=1..K η fk(xi),    fk = 깊이 ≤ 6인 회귀 나무,   η = 0.05,   K = 600 fk는 잎 값 w ∈ ℝT(T = 잎 수 ≤ 26 = 64)를 가진 나무. 예측은 "작은 계단 함수 600개의 합"

③ 손실함수와 학습 과정 추가(XGBoost 원리)

목적함수:  Obj = Σi l(yi, ŷi) + Σk Ω(fk),    Ω(f) = γT + ½ λ ‖w‖2  (잎 수·잎 값 벌점; 기본 γ = 0, λ = 1)
k번째 나무를 더할 때 2차 테일러 전개:  Obj(k) ≈ Σi [ gi fk(xi) + ½ hi fk(xi)2 ] + Ω(fk),   gi = ∂l/∂ŷ, hi = ∂2l/∂ŷ2
제곱 오차 l = ½(y − ŷ)2이면  gi = ŷi − yi (= −잔차), hi = 1
잎 ℓ의 최적 값:  wℓ* = −Gℓ / (Hℓ + λ),   Gℓ = Σi∈ℓ gi, Hℓ = Σi∈ℓ hi
분할 이득:  Gain = ½ [ GL2/(HL+λ) + GR2/(HR+λ) − (GL+GR)2/(HL+HR+λ) ] − γ

학습 과정: (1) ŷ(0) = train 평균 → (2) 각 분자의 gi, hi 계산 → (3) 행 80 %(subsample)·특징 50 %(colsample_bytree)를 뽑아 → (4) Gain이 최대인 분할로 깊이 6까지 나무를 만들고 잎 값 w* 설정 → (5) ŷ ← ŷ + η fk → (2)로. 600회. 제곱 오차에서는 "잔차의 잎 평균을 λ로 눌러서(w = −G/(n+1)) 5 %만 더한다"는 뜻이다. 분할점 탐색은 히스토그램(tree_method='hist')으로 특징값을 구간화해 빠르다 — 지문 2,048비트에서도 4.4 s로 가장 빠른 비선형 모델이었다.

손계산 예 추가

y = (300, 400, 500), 초기 ŷ(0) = 400. 잔차 r = (−100, 0, +100), g = −r = (100, 0, −100), h = 1. 한 잎에 {y=500}만 있으면 G = −100, H = 1, λ = 1 → w* = −(−100)/(1+1) = +50. 학습률 0.05를 곱해 그 분자의 예측은 400 + 2.5 = 402.5 K. 잔차 100 중 2.5만 깎았다 — 이래서 600그루가 필요하고, 그래서 과적합이 서서히 진행되어 조기 종료나 나무 수로 제어할 수 있다.

맞지 않는 점. 외삽 불가와 끝 영역 데이터 부족은 트리 공통의 한계다. 또 결정 패킹·대칭성처럼 기술자에 없는 정보는 어떤 트리도 만들어 낼 수 없다(Mirex, 쿼터페닐).

8. MLP — 층을 쌓은 비선형 함수, GNN으로 가는 다리

① 한 줄 직관 19쪽

입력 특징을 선형 결합 → 비선형(ReLU) → 다시 선형 결합 … 을 층층이 쌓아 복잡한 함수를 만든다. 가중치는 경사하강(Adam)으로 손실이 줄어드는 방향으로 조금씩 고친다. 완전연결 신경망이며, GIN의 각 층 안에도 이 MLP가 들어 있다.

② 가정과 가설 함수

h(1) = ReLU(W(1)x + b(1)) ∈ ℝ256,   h(2) = ReLU(W(2)h(1) + b(2)) ∈ ℝ128,   ŷ = w(3)Th(2) + b(3)
ReLU(z) = max(0, z) W(1) ∈ ℝ256×d, W(2) ∈ ℝ128×256, w(3) ∈ ℝ128. 파라미터 수: d = 217 → (217·256+256) + (256·128+128) + (128+1) = 88,833; d = 2048 → 557,569 (train 3,600개로!)

가정: 특징의 충분히 유연한 합성 함수로 y를 근사할 수 있다(보편 근사). 비선형 활성화가 없으면 층을 아무리 쌓아도 선형 모델과 같다 — ReLU가 "꺾임"을 만들어 조각별 선형 함수가 된다 추가.

③ 손실함수와 학습 과정

L(θ) = (1/2m) Σi (yi − ŷi)2 + (α/2m) ‖θW‖2   (sklearn: 제곱 오차 절반 + L2 벌점 α = 1e-3)
θ ← θ − η · Adam(∂L/∂θ)   (역전파로 기울기 계산, 배치 200개마다 1회 갱신)

학습 과정: (1) 표준화 → (2) train의 10 %를 내부 검증 집합으로 떼어 둠(early_stopping=True) → (3) 가중치 무작위 초기화 → (4) 배치마다 순전파(ŷ 계산) → 손실 → 역전파(연쇄법칙으로 모든 W의 기울기) → Adam 갱신 → (5) epoch 끝마다 검증 점수 확인, 10 epoch 개선 없으면 중단, 최대 300 epoch. 추가 Ridge와 달리 비볼록 문제라 초기값·배치 순서에 따라 다른 국소해에 도달하며(random_state 고정으로 재현), 경사하강의 보폭(lr = 0.001)이 크면 발산, 작으면 느리다. sklearn MLP는 y를 표준화하지 않으므로 mp(수백 K)에서는 초기 손실이 매우 크고 출력층이 그 크기를 따라잡아야 한다.

④ 하이퍼파라미터의 영향

hidden_layer_sizes ↑표현력·파라미터 ↑ → 데이터 적으면 과적합
alpha(L2) ↑가중치 축소 → 과적합 완화, 너무 크면 과소적합
learning_rate크면 진동·발산, 작으면 느림·국소해
early_stopping검증 손실이 다시 커지기 전에 멈춤 10쪽 — 사실상의 정규화; 단 train의 10 %를 잃음
batch_size작으면 잡음 큰 기울기(탐색적), 크면 안정적이지만 일반화가 나빠질 수 있음

⑤ 노트북의 실제 설정

장점

  • 임의의 비선형·상호작용을 표현(보편 근사)
  • 데이터가 늘수록 계속 좋아지는 편(learning curve가 늦게 포화)

  • 해석 어려움(블랙박스)

⑦ mp에서의 정합성·당위성

왜 넣어야 했나. 첫째, GIN으로 가는 다리다. GIN의 각 층은 MLP이고 학습 방식(MSE, Adam, 조기 종료)도 같다. 기술자 위의 MLP와 그래프 위의 GIN을 나란히 두면 "신경망이라서" 좋은지 "그래프라서" 좋은지를 분리할 수 있다. 둘째, 데이터 규모 대비 과적합의 교과서적 예를 보여 준다 — 19쪽의 "데이터 적으면 과적합"이 실제 수치로 나타난다.

맞지 않는 점. 5,000개(실제 학습 3,600개)는 557,569개 파라미터를 가진 모델에는 턱없이 적고, 지문의 희소 입력은 신호가 약해 임의의 함수를 학습한다. 트리처럼 평평하게 외삽하지도 않아 새 골격에서 가장 크게 틀린다. mp처럼 데이터가 수천 개인 물성에서 "기술자 위의 MLP"는 트리 앙상블을 이길 이유가 없다 추가(표 형식 데이터에서 트리가 신경망을 이기는 것은 널리 관찰되는 현상).

⑧ 우리 결과

기술자: random 34.4 K (R² 0.75, 3위 — Ridge급) / scaffold 53.6 K (R² −0.07, 꼴찌 근처). 새 골격 비용 +19 K: 본 골격을 외웠다는 신호.

9. GIN — 분자 그래프에서 표현을 직접 배우는 신경망

① 한 줄 직관 21쪽

원자를 노드, 결합을 엣지로 둔 그래프에서, 각 원자가 이웃 원자들의 벡터를 합해 자기 벡터를 갱신하는 층을 5번 쌓는다(이웃 5칸까지의 정보가 모임). 마지막에 원자 벡터들을 평균해 분자 벡터 하나(hG, 64차원)를 만들고 선형층으로 mp를 낸다. 사람이 정한 기술자 대신 모델이 특징을 배운다 15쪽.

② 가정과 가설 함수

hv(k) = MLP(k)( (1+ε) · hv(k−1) + Σu∈N(v) hu(k−1) ),   k = 1..5,   hv(0) = xv ∈ {0,1}147
hG = READOUT({hv(5)}) = (1/n) Σv hv(5) ∈ ℝ64  (global_mean_pool),    ŷscaled = wThG + b N(v): 원자 v의 이웃 원자 집합, ε = 0 (PyG 기본, 학습 안 함), MLP(k) = Linear → ReLU → Linear (147→128→128, 128→128→128 ×3, 128→64→64), 층 사이 ReLU + dropout 0.3. 파라미터 147,009. 입력 xv는 원소·전하·혼성·H수·방향족·원자가·연결수·고리 + 작용기 SMARTS 110. 결합 특징 16개는 GIN이 쓰지 않는다(GINE이면 사용)

가정: (i) 분자의 물성은 원자와 그 이웃 관계(위상)에서 나온다. (ii) 원자 번호 매기기 순서와 무관해야 한다(순열 불변: 합·평균은 순서를 바꿔도 같음). (iii) 이웃 정보를 합(sum)으로 모으면 이웃의 개수까지 구별된다 — 평균·최댓값은 {A, B}와 {A, A, B, B}를 구별하지 못하지만 합은 구별한다 21쪽 그림. 추가 이 점에서 GIN은 1-WL(Weisfeiler–Lehman) 그래프 동형 검사와 같은 표현력을 갖는, 메시지 전달 신경망 중 가장 표현력이 높은 구조다(Xu et al. 2019). 2D 그래프이므로 3D 배좌·입체·결정 패킹은 입력에 없다.

shape 따라가기 추가 — 피페리딘 C1CCNCC1 (원자 6, 결합 6)

x: (6 × 147), edge_index: (2 × 12)(결합 6개 × 양방향), edge_attr: (12 × 16, GIN은 미사용). 층 1: 원자마다 자기 + 이웃 2개 벡터를 더한 (147,) → MLP → (128,) ⇒ (6 × 128). 층 2–4: (6 × 128). 층 5: (6 × 64). mean pool: (1 × 64). Linear(64→1): (1 × 1) = 표준화된 mp → 역변환 ŷ = z·σtrain + μtrain. 배치 64개 분자는 원자를 이어 붙인 큰 그래프 하나로 처리되고 data.batch가 어느 원자가 어느 분자인지 알려 준다.

③ 손실함수와 학습 과정 (train.py)

학습 손실:  L = MSE(ŷscaled, (y − μtrain)/σtrain)   (표준화된 y; 신경망은 y 크기에 민감) 9쪽
보고 지표:  validate / test MAE [K] (역변환 후)   — 학습과 보고가 다른 함수
갱신:  θ ← θ − η · AdamW(∇θL),   η = 10−3,   기울기 ±10 자르기,   ReduceLROnPlateau(patience 10, ×0.8)

학습 과정: (1) feature.py로 분자 5,000개를 그래프로 → (2) 80/10/10 random 분할(train 4,000 / validate 500 / test 500) → (3) Scaler를 train으로만 fit해 y 표준화(연구실 원본은 train+val+test — 14쪽의 누수 예를 코드가 고침) → (4) epoch마다: 배치 64개씩 순전파 → MSE → 역전파 → AdamW → (5) epoch 끝에 validate MAE 계산, 10 epoch 정체 시 lr ×0.8, 30 epoch 정체 시 중단하고 최선 가중치 복원(조기 종료 10쪽) → (6) test 평가, parity·학습곡선 저장. 우리 실행: 145 epochs(최선 114), 240 s.

⑥ 장점과 단점

장점

  • 사람이 정한 특징이 필요 없음 — 표현을 데이터에서 배움(15쪽 오른쪽 끝)
  • 순열 불변·분자 크기 가변 입력을 자연스럽게 처리
  • sum 집계로 1-WL 수준의 구별력(메시지 전달 중 최고)
  • 데이터가 많아질수록 계속 좋아질 여지; 원자 기여·BGNN σ로 확장(4주차, 22쪽)
  • 우리 결과: 지문 기반 6모델은 모두 이김

단점

  • 데이터를 많이 요구(“1만 개 이상” 19쪽); 5,000개에서는 기술자 XGBoost·RF에 뒤짐
  • 학습 비용 240 s vs XGBoost 5 s; 하이퍼파라미터 많음
  • mean pool이 크기 정보를 지움 → 작은 분자에서 큰 오차(바이닐 아세테이트 177 → 388 K)
  • 2D 그래프: 입체·3D·결정 패킹 없음 — mp의 핵심 변수가 입력에 없음
  • 해석이 어려움(원자 기여는 4주차)

⑦ mp에서의 정합성·당위성

왜 넣어야 했나. 첫째, 연구실의 실제 물성 모델(BGNN_unary)이 이 구조이므로 21, 26쪽, 고전 모델 사다리의 꼭대기와 비교해 "구조를 직접 배우는 것이 지금 데이터 규모에서 이득인가"를 묻는 것이 1주차 과제의 핵심 질문이다(49쪽 4단계). 둘째, 기술자·지문은 사람이 미리 정한 요약이라 정의되지 않은 패턴(특정 원자 배열)은 담을 수 없지만 GNN은 배울 수 있다 — mp처럼 치환기 위치·대칭성 같은 "배치"가 중요한 물성에서 이 가능성은 시험할 가치가 있다. 셋째, 2·3·4주차의 모든 변경(readout, GINE, BGNN, XAI)이 이 모델 위에서 이루어진다.

맞지 않는 점(지금 단계에서). 데이터 5,000개는 경계 아래이고, mean pool은 크기 의존을 지우며, 결합 특징을 버린다. 그리고 가장 근본적으로, 녹는점을 좌우하는 결정 패킹·대칭성·분자간 수소결합은 2D 그래프 안에 없다 추가. 따라서 GIN이 기술자 XGBoost를 못 넘은 것은 "GNN이 나빠서"가 아니라 "데이터 규모 + 입력 정보 + readout" 세 가지가 아직 맞지 않아서다 — 2주차에 바꿀 것이 바로 그것들이다.

  • 표현이 모델보다 컸다: 같은 모델에서 기술자 → 지문으로 바꾸면 1.2–2.2배 나빠졌고, 같은 표현에서 모델을 바꾸는 차이(기술자 30–38 K)는 그보다 작다. mp는 "분자 전체의 극성·크기·강직성 요약"이 좌우하는 물성이라 기술자가 맞고, 부분구조 유무(지문)는 그 요약을 간접적으로만 담는다.
  • 트리가 1·2위: 수천 개 표 형식 데이터 + 상호작용 + 스케일 무관 + 이상치 둔감. 외삽 불가는 끝 영역에서만 대가를 치렀다.
  • 거리·내적 모델이 지문에서 무너짐: 표준화된 희소 0/1 비트에서 희귀 비트가 거리(kNN, SVR)·계수(Ridge)·기울기(MLP)를 독점. 트리는 비트를 있다/없다로만 보므로 무사했다.
  • GIN은 3위: 데이터 5,000은 경계 아래, mean pool은 크기를 지움, 결정 정보는 입력에 없음. 그러나 지문 6종은 모두 이겼다 — "모델이 배우는 특징"이 "사람이 정한 부분구조 특징"보다는 나았다.

11. 표현 × 모델의 궁합 — 결과가 왜 그렇게 나왔는가

11.1 기술자 217개가 mp에 맞는 이유

RDKit 기술자에는 mp를 결정하는 물리량의 대리변수가 직접 들어 있다: TPSA(극성 표면 → 쌍극자·수소결합), NumHDonors·NHOHCount(결정 내 수소결합 네트워크), RingCount·fr_bicyclic(강직성 → 녹을 때 엔트로피 이득 작음 → mp ↑), NumRotatableBonds·FractionCSP3(유연성 → 패킹 느슨 → mp ↓), BertzCT·MolWt(크기 → 분산력). SHAP 상위 7개가 정확히 이것들이었고, 방향도 모두 화학 상식과 맞았다. 즉 기술자는 이미 "절반쯤 모델"이다 — 사람이 물리를 넣어 둔 특징이라 데이터가 적어도 잘 작동한다 15쪽 "사람이 정한 특징".

11.2 Morgan 지문이 mp에 약한 이유

지문은 "반경 2 안의 부분구조가 있다/없다"의 2,048비트다. 작용기 효과(이 치환기가 있으면 +ΔT)는 담지만, 분자 전체의 극성 총량·크기·고리 수 같은 집계량은 비트 여러 개의 합으로만 간접 표현된다. 게다가 분자당 켜진 비트가 평균 25.9개(1.3 %)로 희소하고, 희귀 비트가 전체의 79 %(1,608 / 2,048 비트가 빈도 1 % 미만)다. 이 희소성이 모델별로 다른 재앙을 부른다:

11.3 그래프가 "모델이 배우는 특징"인 이유와 대가

GIN의 hG(64차원)는 학습이 끝난 뒤 보면 "이 데이터에 맞춰 만들어진 기술자"다. 원자 특징 147개에서 시작해 이웃 5칸의 패턴을 합성하므로 사람이 정의하지 않은 부분구조도 담을 수 있다. 대가는 그 특징을 데이터에서 배워야 한다는 것 — 5,000개는 부족했고(3위), 평균 풀링이 크기를 지워 작은 분자에서 틀렸다. 그래도 지문보다 나았다는 사실은, 같은 "부분구조" 정보라도 고정 해시(지문)보다 학습된 합성(GNN)이 낫다는 뜻이다.

그림 1. 결과표 — 모델 6 × 표현 2 × 분할 2, test MAE [K]. 굵게 = 열 최저, × = 기준선보다 나쁨. 기술자 열이 지문 열보다 일관되게 낮고, 트리 두 모델이 네 열 모두 상위.

12. 결론 — 이 주제에서 모델 선택의 당위성 종합

12.1 "왜 이 모델들이어야 했나"에 대한 답

  1. 방법론적 당위성: 회귀 문제에서 모델의 가치는 절대 점수가 아니라 사다리 위의 위치로 읽힌다. 기준선(72.5 K) → 선형(35.4) → 커널·이웃(35–38) → 트리 앙상블(30–33) → 신경망(34) → 그래프 신경망(36.5, 다른 test)의 사다리가 있었기에 "비선형은 5 K, 앙상블은 2 K, GNN은 아직 −" 같은 말을 할 수 있다 19쪽.
  2. 가정의 다양성: 일곱 모델은 가법성·국소 유사성·매끄러움·축 정렬 구간·합성 비선형·관계 구조라는 서로 다른 귀납 편향을 대표한다. 어느 가정이 mp와 맞는지는 돌려 봐야 알며, 결과는 "축 정렬 구간 + 상호작용(트리)"이 가장 맞고 "국소 유사성(kNN)"이 가장 안 맞는다고 말해 주었다 — 이것은 mp가 작은 구조 변화에 민감하고(cliff) 특징 상호작용이 큰 물성이라는 화학적 사실과 일치한다.
  3. 표현과의 교차 설계: 같은 여섯 모델을 두 표현에 돌렸기 때문에 "표현 효과(기술자 vs 지문: 1.2–2.2배)"와 "모델 효과(30–38 K)"를 분리할 수 있었다. 하나의 표현만 썼다면 kNN의 실패를 "kNN이 나쁘다"로 잘못 읽었을 것이다.
  4. mp의 성격과의 정합: 측정 잡음(86종 ≥ 50 K)이 크고 결정 성질이라 2D 표현의 한계가 있는 물성이다. 따라서 (i) 모든 모델이 300–450 K에서 27–32 K로 수렴하는 "잡음 하한" 근처의 비교이고, (ii) 외삽 불가(트리)보다 입력 정보 부재(대칭성·패킹)가 더 근본적인 한계이며, (iii) 설명(SHAP·틀린 분자)이 데이터 오류를 찾아내는 실용적 가치를 가진다. 이 세 가지를 모두 보여 줄 수 있는 모델 구성이었다.
  5. 다음 단계와의 연결: GIN은 2·3·4주차(readout·GINE·BGNN·XAI)의 기반이고, XGBoost+SHAP은 그 결과를 대조할 "설명 가능한 최고 고전 모델"이다. 1주차의 선택은 이후 주차의 비교 기준을 세우는 선택이기도 했다.

12.2 한 문장 정리

mp 예측은 "수천 개의 잡음 큰 회귀 데이터"이며, 이런 문제에서는 물리를 담은 기술자 위의 트리 앙상블(XGBoost 30.0 / 37.8 K)이 기본 설정만으로 가장 믿을 만한 답을 주고, 선형·이웃·커널·신경망 모델은 그 답이 얼마나 좋은지, 무엇 때문에 좋은지를 재는 자가 된다. 그래프 신경망(GIN 36.5 K)은 아직 데이터·readout·입력 정보가 모자라 3위에 머물렀지만, 지문 기반 모델을 모두 이겼고 2주차에 바꿀 것이 분명하다는 점에서 가장 많은 것을 가르쳐 준 모델이다.

12.3 2주차에 바꿀 것 (후분석이 가리킨 순서) 49쪽

  1. --pooling sum: mean pool이 분자 크기를 지워 작은 분자에서 틀린다 → GIN 논문의 readout(sum)으로.
  2. --conv GINE: 결합 특징 16개(공액·회전 가능)를 쓰도록 — 회전 가능 결합은 SHAP 6위의 중요한 변수.
  3. --max_n 0: 전체 19,945개로 learning curve 확인 — GNN은 데이터가 적을수록 불리 19, 23쪽.
  4. (고전 모델 쪽) 지문에는 Tanimoto 거리·표준화 생략을, Ridge에는 더 큰 λ를 — 단 test를 보고 고르지 말고 train 안의 교차검증으로.
