### 1.2 핵심 요소 목록

- **모델**: Ridge(선형 + L2), kNN, Random forest, XGBoost, SVR(RBF 커널), MLP, GNN(GCN, GIN), BGIN(GIN + 베이지안 층). 언급만: GP, BO, NSGA-II, KA-GNN, 베이지안 LSTM
- **학습 방식**: 지도(1–3주차 중심), 비지도(4주차 manifold), 자기지도(GNN 사전학습), 강화(다루지 않음)
- **문제 유형**: 회귀(물성 9종 모두). 분류는 회귀값에 기준선을 그어 만들 수 있다는 예(pKa > 9 → 강염기)로만 등장
- **손실/목적함수**: MSE(학습), MAE(보고, 조기 종료), 교차 엔트로피(분류, 언급), 공정 목적 J = B 수율 − 0.3·τ/1000 (35쪽)
- **최적화**: 경사하강법 w ← w − η·dL/dw, AdamW(lr 0.001), BO(GP + EI)
- **평가**: MAE, RMSE, 기준선 MAE(train 평균으로 예측), parity plot, learning curve, Tanimoto 유사도(지문 비교)
- **주요 정의**: 잔차, 손실, 학습, 매개변수 θ, 과소적합, 과적합, 조기 종료, canonical SMILES, Murcko scaffold, 누수, ECFP4, 메시지 전달, readout, WL test, μ와 σ, 디지털 트윈, 서로게이트, 소프트 센서, Pareto 해
- **주요 그래프**: 잔차 그림(7), 손실 곡선 위 경사하강 경로(9), 다항식 적합과 validation curve(10), 모델별 외삽(20), 집계 비교(21), 지문 공간 σ 지도(22), parity(23–26), loss vs epoch(24, 39), 정확도–설명 개념도(31), 이익 지도와 BO 수렴(35)
- **주요 코드**: `load_data → gen_dataset → transform_y → split_dataset` (11, 14), `Descriptors.CalcMolDescriptors` (16), `GetMorganGenerator(radius=2, fpSize=2048)` (17), `global_mean_pool` (5, 21), `python train.py --prop <물성>` (39, 49)

**핵심 수식 카드**

| 수식 | 쪽 | 변수·shape | 주의 |
|---|---|---|---|
| ŷ = f(x; θ), 잔차 = y − ŷ | 7 | x: 분자 표현, y: 물성, θ: 매개변수 | 잔차 = 측정 − 예측 |
| MSE = (1/n) Σ (y − ŷ)² | 9 | y, ŷ ∈ ℝⁿ → 스칼라, 단위² | 큰 오차에 큰 벌점 |
| MAE = (1/n) Σ \|y − ŷ\| | 9, 23 | 단위 = 물성 단위 | 보고용 |
| RMSE = √( (1/n) Σ (ŷ − y)² ) | 23 | 단위 = 물성 단위 | 항상 RMSE ≥ MAE |
| w ← w − η · dL/dw | 9 | η: 학습률 | 부호가 −, η에 상한 있음 |
| h_v⁽ᵏ⁾ = MLP⁽ᵏ⁾( (1 + ε)·h_v⁽ᵏ⁻¹⁾ + Σ_{u∈N(v)} h_u⁽ᵏ⁻¹⁾ ) | 21 | h_v ∈ ℝ¹²⁸ (연구실 hidden) | 이웃 집계 = sum |
| h_G = READOUT({h_v⁽ᴷ⁾ \| v ∈ G}) → 선형층 → 물성값 | 21 | h_G ∈ ℝ¹²⁸ | 연구실 readout = mean pool |
| σ = log(1 + exp(ρ)) | 3 (그림) | 가중치 분포 N(μ, σ²)의 매개변수 (μ, ρ) | σ > 0 보장 |
| J = B 수율 − 0.3·τ/1000 | 35 | τ: 체류시간 [s] | 수율만 최대화하면 범위 끝으로 감 |
| [추가] z = (x − μ_train) / σ_train | 16 | 특징 열마다 | train으로만 fit |
| [추가] Tanimoto T = c / (a + b − c) | 17 | a, b: 켜진 비트 수, c: 공통 비트 수 | 0 ≤ T ≤ 1 |

#### [Slide 2] 왜 물성 예측인가 · ★★★

**① 반드시 이해할 것**

**② 한 줄 핵심**: 물성 예측 모델은 측정할 수 없을 만큼 많은 후보를 공정 계산에 넣기 위한 1차 거름망이다.

- **연결**: → 3쪽(스크리닝 계획), 48쪽(팀 물성이 공정 어디에 쓰이는지 한 줄 쓰기).

#### [Slide 3] 2024 연구계획: 물성 예측 모델 → 아민 스크리닝 · ★★★

**① 반드시 이해할 것**
- 1단계: 공정 중요물성 예측 모델. 그림 흐름 = 원자 특징 147개·결합 특징 17개 생성 → 그래프 합성곱 → pooling → Bayesian layer → 물성값과 불확실성(예: pKa 9.7 ± 0.3).
- 2단계: 같은 모델로 아민 스크리닝과 우선순위. 거름 기준 두 가지 = 예측값 μ가 목표 범위 안인가, 불확실성 σ가 얼마나 큰가.
- 1–2주차 = 1단계의 기초(전처리, 표현, 모델 비교), 3주차 = 2단계의 불확실성과 결정.
- 그림 오른쪽: deterministic sense(μ 한 점이 범위 안/밖) vs probabilistic sense(예측 분포가 목표 범위와 겹치는 면적 = score) → 이 score로 후보 순위.

**② 한 줄 핵심**: 예측값만이 아니라 예측의 불확실성까지 써서 후보 순위를 매기는 것이 연구의 최종 목표다.

- **그림 속 학습 설정**: dropout 0.3(GNN)/0.0(BGNN), BGNN 예측 샘플 100회, warm start(GNN 가중치로 BGNN 시작), batch 64/256/1024, 층 5개, AdamW + 학습률 스케줄링 + gradient clipping, 분할 0.8/0.1/0.1.
- **수식(그림)**: 가중치 분포 매개변수 Φ = (μ, ρ), σ = log(1 + exp(ρ)) → σ가 음수가 되지 않게 함. 자세한 해석은 22쪽.
- **[추가] probabilistic score 계산 예**: 예측 분포 N(μ = 9.7, σ = 0.3), 목표 범위 9 ≤ pKa ≤ 10(가정)이면 P = Φ((10 − 9.7)/0.3) − Φ((9 − 9.7)/0.3) = Φ(1.00) − Φ(−2.33) = 0.8413 − 0.0098 ≈ 0.83. μ가 같아도 σ가 커지면 이 면적이 줄어 순위가 내려간다. (Φ = 표준정규 누적분포)
- **주의**: 이 그림은 GAT·결합 특징 17개·hidden 129로 표기되어 있어 21쪽(GIN, hidden 128), 18쪽(결합 16)과 판이 다르다. 보고할 때는 코드 판과 특징 차원을 함께 적는다(18쪽).

### Unit B. ML 기초 (7–10쪽)

#### [Slide 7] ML 기초 1: 물성 = f(분자) · ★★★★★

**① 반드시 이해할 것**
- 머신러닝 = 데이터 (x, y)에서 y = f(x)를 찾는 것. f의 형태(직선, GNN)를 정하면 남는 미지수가 매개변수 θ다.
- 잔차 = 측정값 − 예측값, 손실 = 잔차 전체를 숫자 하나로 요약한 값, 학습 = 손실이 작아지도록 θ를 조정하는 것.
- θ 개수: 직선은 2개(기울기, 절편), GNN은 10만 개 이상 → 표현력과 필요한 데이터 양이 다르다.
- 잔차의 **패턴**(양 끝 음수, 가운데 양수)은 직선이 데이터의 휘어짐을 못 담는다는 신호 = 과소적합(10쪽).

**② 한 줄 핵심**: 물성 예측은 분자 표현 x → 물성 y 함수를 데이터에 맞추는 일이고, "맞춘다"는 것은 잔차를 요약한 손실이 작아지도록 θ를 고르는 것이다.

**③ 직관**
- [직관적 이해] 점들 사이에 자를 대고 선을 긋되, 빗나간 정도의 총량이 가장 작게 긋는다.
- [정확한 ML적 의미] **[추가]** 가설 공간 {f(x; θ)} 안에서 경험적 손실 L(θ) = (1/n) Σ ℓ(yᵢ, f(xᵢ; θ))를 최소화하는 θ를 찾는다(경험적 위험 최소화). 가설 공간 밖의 패턴(휘어짐)은 θ를 아무리 조정해도 못 잡는다.

**수식 해석: f(x) = 35.5x + 114**
- 변수: x = 탄소 수(무차원 정수, 1–10), y = n-알케인 정상 끓는점 [K], θ = (기울기 35.5 K/탄소, 절편 114 K)
- shape **[추가]**: 샘플 n = 10, 특징 1개 → X ∈ ℝ¹⁰ˣ¹, y ∈ ℝ¹⁰, θ ∈ ℝ²
- 의미: 직선 가정 아래에서 탄소 하나 추가 → 끓는점 평균 35.5 K 증가. 절편 114 K는 x = 0(탄소 0개)으로의 외삽값이라 물리적 의미는 없다 **[추가]**.
- **[검증]** NIST 정상 끓는점으로 최소제곱 직선을 다시 구하면 35.55x + 113.78 → 슬라이드 직선과 일치. 잔차 C1 −37.8 K, C5 +17.7 K(슬라이드 −38, +18).

**그래프 해석 (n-알케인 C1–C10 끓는점)**
- x축: 탄소 수 / y축: 끓는점 [K] / 점 = 측정값, 파란 선 = 모델, 주황 세로선 = 잔차
- 증감: 탄소 수가 늘면 끓는점이 오르지만 증가폭이 줄어든다 **[검증]** (C1→C2 +72.9 K, C5→C6 +32.7 K, C9→C10 +23.3 K) → 데이터는 위로 볼록(오목 함수)
- 특정 영역: 직선의 기울기는 일정 → 양 끝에서 과대 예측(잔차 음수), 가운데에서 과소 예측(잔차 양수)
- 모델과 연결: 잔차가 무작위가 아니라 x에 따라 체계적으로 변함 = 모델 형태(가설)가 부족 = 편향(bias) → 과소적합. 잔차가 무작위로 흩어져 있다면 모델을 복잡하게 할 근거가 약하다.

**연결**: (첫 ML 슬라이드) → 8쪽 문제 유형, 9쪽 손실 정의와 θ 조정 방법(경사하강법), 10쪽 과소적합.

**문제 유형 / 자주 하는 실수**
- 유형: 계산형(예측값, 잔차, MSE·MAE), 그래프 해석형(잔차 패턴 → 과소적합), 정의형(x, y, f, θ)
- 실수: 잔차 부호를 예측 − 측정으로 뒤집음(그림의 위/아래 해석이 반대가 됨) / 절편을 물리량으로 해석 / "θ가 많을수록 좋다"(10쪽 과적합)

**암기 vs 이해**
- 암기: 잔차 = 측정 − 예측, 손실 = 잔차 요약, 학습 = 손실이 줄도록 θ 조정, 직선 θ 2개 vs GNN θ 10만+
- 이해: 잔차의 체계적 패턴이 왜 "모델 형태 부족"의 증거인가, 왜 θ 수가 필요한 데이터 수와 연결되는가

**예시 문제** [추가]

**[문제]** 7쪽 직선 f(x) = 35.5x + 114 (x = 탄소 수, y = 정상 끓는점 [K])가 있다. 측정값이 C1 111.7 K, C5 309.2 K, C10 447.3 K일 때 (a) 세 분자의 예측값과 잔차, (b) 세 점에 대한 MAE, MSE, RMSE를 구하고, (c) 잔차 부호로 모델 상태를 진단하라.

**[난이도]** ★★
**[무엇을 구해야 하는가?]** ŷ, 잔차, MAE·MSE·RMSE, 진단(과소/과적합)
**[사용해야 할 개념]** 잔차 정의(7쪽), MSE·MAE(9쪽), RMSE(23쪽), 과소적합(10쪽)
**[풀이 전략]** 잔차 부호 정의(측정 − 예측)를 먼저 고정하고, 단위(K, K²)를 끝까지 추적한다.

- **[Step 1] 조건 정리**: x = 1, 5, 10 / y = 111.7, 309.2, 447.3 K / θ = (35.5 K/탄소, 114 K) / n = 3
- **[Step 2] 유형 판별**: 회귀 모델의 손계산 평가
- **[Step 3] 식 선택**: ŷ = 35.5x + 114, e = y − ŷ, MAE = mean\|e\|, MSE = mean(e²), RMSE = √MSE
- **[Step 4] 식 변형**: 없음(직접 대입)
- **[Step 5] 단위 확인**: ŷ, e, MAE, RMSE → K / MSE → K²
- **[Step 6] 계산**
  - ŷ = 149.5, 291.5, 469.0 K → e = −37.8, +17.7, −21.7 K
  - Σ\|e\| = 77.2 → MAE = 25.73 K
  - e² = 1428.84, 313.29, 470.89 → Σ = 2213.02 → MSE = 737.67 K² → RMSE = 27.16 K

**[최종 답]** (a) 예측 149.5 / 291.5 / 469.0 K, 잔차 −37.8 / +17.7 / −21.7 K (b) MAE 25.7 K, MSE 737.7 K², RMSE 27.2 K (c) 양 끝 음수·가운데 양수의 체계적 패턴 → 과소적합

**[모델 관점의 의미]** 특징 하나(탄소 수) + 직선으로는 곡률을 못 담는다 → 2차항 추가나 비선형 모델이 필요. 10점 전체로 계산하면 MAE 13.9 K, RMSE 17.3 K [검증].
**[주의할 점]** MSE 단위는 K²라 MAE와 직접 비교하지 않는다. 3점 MAE를 전체 MAE로 착각하지 않는다.

#### [Slide 8] ML 기초 2: 학습 방식, 회귀 vs 분류 · ★★★★

**① 반드시 이해할 것**
- 학습 방식은 "정답 y가 있는가, 어디서 오는가"로 나뉜다: 지도학습 (x, y) 쌍 / 비지도학습 x만(군집, 차원 축소) / 자기지도학습 x만이지만 정답을 x에서 만듦(가린 원자 맞히기 → 사전학습) / 강화학습 행동과 보상.
- 이 스터디 = 지도학습 회귀(정답 y가 붙은 분자로 연속값 예측). 물성 9종 모두 회귀.
- 회귀(y 연속: 끓는점 350 K, logP 2.1) → 손실·평가 MSE, MAE / 분류(y 범주: 1차·2차·3차 아민, 독성 유무) → 교차 엔트로피, 정확도.
- 회귀값에 기준선을 그으면 분류로 바뀐다(pKa > 9 → 강염기).

**② 한 줄 핵심**: 같은 분자 데이터라도 "y가 무엇인가"가 학습 방식과 손실 함수를 정한다.

**③ 직관**
- [직관적 이해] 자기지도학습 = 문제집의 빈칸을 스스로 만들어 푸는 공부. 정답을 사람이 붙일 필요가 없다.
- [정확한 ML적 의미] **[추가]** 자기지도 사전학습은 라벨 없는 대량 분자로 표현을 먼저 학습하고, 라벨 있는 소량 물성 데이터로 미세조정하는 데 쓰인다(29쪽 계보의 Hu 2020).

**표 해석 (스터디 위치)**: 지도학습 = 1–3주차 중심 / 비지도 = 4주차 manifold(PCA, PaCMAP) / 자기지도 = 29쪽 GNN 계보 / 강화학습 = 다루지 않음(분자 생성, 합성 경로 예)
- **[추가]** 이진 교차 엔트로피: L = −[y log p̂ + (1 − y) log(1 − p̂)], p̂ = 양성 확률(0–1). 분류에 MSE를 쓰지 않는 이유는 확률 출력과 결합했을 때 기울기가 작아지는 구간이 생기기 때문(분류는 이 스터디 범위 밖).

**연결**: ← 7쪽(y = f(x)) / → 9쪽(회귀 손실 MSE·MAE), 29쪽(자기지도 사전학습), 4주차(비지도 manifold).

**문제 유형 / 자주 하는 실수**
- 유형: 구분형(주어진 과제의 학습 방식·문제 유형), 변환형(임계값으로 라벨 만들기)
- 실수: 자기지도학습을 비지도학습과 같은 것으로 묶음 / 임계값 경계(> vs ≥) 처리 누락 / **[추가]** logistic regression을 이름 때문에 회귀로 분류(실제는 분류 모델)

**암기 vs 이해**
- 암기: 4가지 학습 방식의 데이터 형태, 회귀·분류별 손실과 지표
- 이해: 회귀 → 분류 변환 시 잃는 정보(얼마나 강한 염기인지), 이 스터디가 회귀인 이유(물성이 연속값)

#### [Slide 9] ML 기초 3: 손실 함수와 경사하강법 · ★★★★★

**① 반드시 이해할 것**
- 손실 = 틀린 정도를 숫자 하나로. MSE는 큰 오차에 큰 벌점 + 미분이 매끄러움 → 학습용, MAE는 단위가 물성과 같음 → 보고용.
- 실습 GNN 코드: 학습 = MSE, 조기 종료·보고 = MAE → 학습 손실과 평가 지표는 다를 수 있다.
- 갱신 규칙 w ← w − η · dL/dw: 기울기의 반대 방향으로 η만큼 이동.
- η(학습률) = 한 번에 움직이는 폭. 작으면 느림, 크면 바닥을 넘나듦, 더 크면 발산. 그림 예에서 η > 1이면 발산.

**② 한 줄 핵심**: 손실은 "얼마나 틀렸나"를 숫자 하나로 만들고, 경사하강법은 그 숫자가 줄어드는 방향(기울기의 반대)으로 θ를 η만큼씩 옮긴다.

**③ 직관**
- [직관적 이해] 안개 낀 골짜기에서 발밑 경사만 보고 내려간다. 보폭(η)이 너무 크면 골짜기 건너편으로 넘어가 버린다.
- [정확한 ML적 의미] **[추가]** 1차 근사 L(w + Δ) ≈ L(w) + L′(w)·Δ에서 Δ = −η·L′(w)로 두면 손실 변화 ≈ −η·L′(w)² ≤ 0. 단, 이 근사는 Δ가 작을 때만 맞으므로 η에 상한이 생긴다.

**수식 해석 1: MSE = (1/n) Σ (y − ŷ)², MAE = (1/n) Σ \|y − ŷ\|**
- 변수: n = 샘플 수, y = 측정값, ŷ = 예측값, Σ = 샘플 i = 1…n에 대한 합
- shape·범위: y, ŷ ∈ ℝⁿ → 스칼라. MSE ≥ 0(단위²), MAE ≥ 0(물성 단위), 0이면 완벽
- 증감: 오차 하나가 2배가 되면 그 항의 기여가 MSE에서 4배, MAE에서 2배
- **[추가]** 기울기: ∂(y − ŷ)²/∂ŷ = −2(y − ŷ)(오차 크기에 비례, 바닥 근처에서 작아짐) / ∂\|y − ŷ\|/∂ŷ = −sign(y − ŷ)(크기와 무관, 0에서 미분 불가) → MSE가 학습에 매끄럽다는 슬라이드 설명의 근거
- 언제: 학습 → MSE, 보고 → MAE. 주의: log 목표값이면 두 값 모두 log 단위(13쪽)

**수식 해석 2: w ← w − η · dL/dw**
- 변수: w = 매개변수, η = 학습률(η > 0), dL/dw = 손실의 기울기
- 부호: dL/dw > 0(w를 키우면 손실 증가) → w 감소. "기울기 방향"이 아니라 "기울기 반대 방향"
- 증감: η ↑ → 한 걸음 ↑ → 초반은 빠르지만 진동·발산 위험

**유도: 그림 설정에서 "η > 1이면 발산"이 나오는 이유** [추가]

```
표준화: x_s = (x − x̄)/s_x,  y_s = (y − ȳ)/s_y          (s = 모집단 표준편차)
→ (1/n)Σx_s² = 1,  (1/n)Σy_s² = 1,  (1/n)Σx_s·y_s = r   (r = 상관계수)
모델: ŷ_s = w·x_s   (표준화하면 절편 = 0이므로 w 하나만 학습)

L(w)   = (1/n)Σ(y_s − w·x_s)² = 1 − 2rw + w²     ← 포물선(볼록)
dL/dw  = 2(w − r)                                ← 최솟값 w* = r,  L(w*) = 1 − r²
갱신   : w_{k+1} = w_k − η·2(w_k − r)
     ⇒ (w_{k+1} − r) = (1 − 2η)·(w_k − r)        ← 매 단계 남은 거리에 (1 − 2η)를 곱함

수렴 조건  |1 − 2η| < 1  ⇔  0 < η < 1
  0 < η < 0.5 : 같은 쪽에서 단조 접근        (그림 a, η = 0.2 → 거리 × 0.6)
  η = 0.5     : 한 번에 최솟값
  0.5 < η < 1 : 좌우로 넘나들며 수렴        (그림 b, η = 0.95 → 거리 × (−0.9))
  η > 1       : |1 − 2η| > 1 → 발산
```

- **[검증]** 알케인 데이터: r = 0.986 → w* = 0.986, L(−1) = 3.97(그림 시작점 MSE ≈ 4), L_min = 0.028.
  - η = 0.2: w = −1 → −0.21 → 0.27 → 0.56 → 0.73 → 0.83 → 0.89 → 0.93 → 0.95 (8단계)
  - η = 0.95: w = −1 → 2.77 → −0.62 → 2.43 → −0.32 → 2.16 → −0.07 → 1.94 → 0.13 (그림 b의 좌우 점과 일치)
  - η = 1.05: −1 → 3.17 → −1.42 → 3.63 → … (발산)
- **[추가]** 일반화: 이차 손실에서 안정 조건은 η < 2 / (손실의 곡률). 이 예는 곡률 L″ = 2라서 η < 1. 매개변수가 여러 개면 가장 가파른 방향의 곡률(헤시안 최대 고윳값)이 상한을 정한다. GNN이 lr 0.001 같은 작은 값과 AdamW를 쓰는 배경이다(21쪽).

**그래프 해석 (a: η = 0.2, b: η = 0.95)**
- x축: 기울기 w(표준화 데이터라 무차원) / y축: MSE(표준화 단위)
- 곡선: L(w) = 1 − 2rw + w², 볼록 → 전역 최솟값 하나(w* ≈ 0.99)
- 기울기: 각 점의 접선 기울기 = dL/dw = 2(w − r). 바닥에서 멀수록 가파름 → 같은 η라도 초반 걸음이 크고 바닥 근처에서 작아짐(그림 a의 점 간격이 줄어드는 이유)
- 곡률: L″ = 2로 일정 → η 상한 1을 결정
- 특정 영역: b는 바닥을 사이에 두고 좌우 교대(남은 거리 × −0.9) → 8단계 후에도 0.13에 머묾. a는 0.95까지 접근 → η가 크다고 빨리 수렴하지 않는다
- 임계점: η = 0.5(단조/진동 경계), η = 1(수렴/발산 경계)
- 모델과 연결: 실제 학습의 loss vs epoch 곡선이 진동하면 η 과대를 먼저 의심한다(24쪽 pKa BGNN 불안정 사례 참고).

**연결**: ← 7쪽(손실, θ 조정) / → 10쪽(언제 멈추나: 조기 종료), 21쪽(AdamW, lr 0.001), 23쪽(MAE·RMSE 보고), 6쪽(2024 직접 구현).

**문제 유형 / 자주 하는 실수**
- 유형: 계산형(한 스텝 갱신, MSE·MAE), 그래프 해석형(η 비교), 개념형(MSE vs MAE 용도)
- 실수: 갱신식 부호를 + 로 씀 / "η가 클수록 빨리 수렴" / MSE(K²)와 MAE(K)를 같은 단위로 비교 / 학습 손실과 보고 지표를 같은 것으로 생각

**암기 vs 이해**
- 암기: MSE·MAE 식, w ← w − η·dL/dw, η 효과 3단계(느림 / 진동 / 발산)
- 이해: 왜 기울기 반대 방향이 감소 방향인가, 왜 η에 상한이 있는가(곡률), 왜 학습은 MSE·보고는 MAE인가

**예시 문제** [추가]

**[문제]** 9쪽 그림처럼 알케인 데이터를 표준화하고 기울기 w 하나만 학습한다. 표준화된 x, y의 상관계수는 r = 0.986이다. (a) L(w) = (1/n) Σ (y_s − w·x_s)²를 w의 식으로 쓰고 dL/dw를 구하라. (b) w₀ = −1에서 η = 0.2와 η = 0.95로 각각 한 번 갱신한 w₁과 L(w₁)을 구하라. (c) 수렴하는 η의 범위와, 단조 수렴·진동 수렴의 경계를 구하라.

**[난이도]** ★★★
**[무엇을 구해야 하는가?]** L(w), dL/dw, 한 스텝 후 w₁과 손실, η 조건
**[사용해야 할 개념]** MSE(9쪽), 갱신 규칙(9쪽), 표준화 **[추가]**
**[풀이 전략]** 표준화의 성질(평균 0, 분산 1, 곱의 평균 = r)로 L을 w의 이차식으로 만든 뒤, 갱신식을 "남은 거리"의 점화식으로 바꾼다.

- **[Step 1] 조건 정리**: (1/n)Σx_s² = (1/n)Σy_s² = 1, (1/n)Σx_s y_s = r = 0.986, w₀ = −1, η ∈ {0.2, 0.95}
- **[Step 2] 유형 판별**: 최적화(경사하강법) 계산형
- **[Step 3] 원리 선택**: MSE를 전개하고 w ← w − η·dL/dw 적용

- **[Step 5] 범위 확인**: L ≥ 1 − r² = 0.028 > 0, w는 무차원
- **[Step 6] 계산**

  - η = 0.95: w₁ = −1 + 0.95·3.972 = 2.773, L(w₁) = 1 − 2(0.986)(2.773) + 2.773² = 3.223

#### [Slide 10] ML 기초 4: 과소적합, 과적합, train / validate / test · ★★★★★

**① 반드시 이해할 것**
- 목표 = 처음 보는 분자에서 작은 오차. train 점수만으로는 판단할 수 없다.
- 과소적합: train, validate 오차 모두 큼(그림 a, 차수 1). 과적합: train 작음, validate 큼(그림 c, 차수 11). validate MSE 최소 = 차수 4.
- 세트 역할: train = 매개변수 θ 학습(매 단계) / validate = 설정 선택, 조기 종료(학습 중) / test = 최종 성적 1회(마지막).
- 조기 종료: validate 오차가 다시 커지기 전에 멈춘다. 나누는 방법은 14쪽(random vs scaffold).

**② 한 줄 핵심**: 모델이 복잡해질수록 train 오차는 계속 줄지만 validate 오차는 U자를 그리므로, validate 최소점에서 설정을 고르고 test는 마지막에 한 번만 본다.

**③ 직관**
- [직관적 이해] 기출문제 답만 외운 학생(과적합)과 개념이 부족한 학생(과소적합). 모의고사(validate)로 공부법을 고르고, 실제 시험(test)은 한 번만 본다.
- [정확한 ML적 의미] **[추가]** 제곱 오차 기준 기대 오차 = 편향² + 분산 + 잡음. 차수 ↑ → 편향 ↓, 분산 ↑. validate 최소점이 둘의 균형점이다. 잡음 항은 어떤 모델로도 줄일 수 없다.

**그래프 해석 (a–c: 적합 곡선, d: 오차 vs 복잡도)**
- a–c 축: x(0–6) vs y / 점선 = 참 함수(사인), 주황 원 = train 14점, 초록 네모 = validate 14점, 파란 선 = 모델
  - a(차수 1): 직선 → 사인 곡선을 못 따라감 → train, validate 모두 큼
  - b(차수 4): 참 함수에 가깝게 따라감 → validate 최소
  - c(차수 11): train 점은 거의 지나지만 점 사이에서 크게 출렁이고 양 끝(x < 0.3, x > 5.9)에서 튐 → validate 큼
- d 축: x = 모델 복잡도(다항식 차수 0–11), y = MSE(**log 스케일**, 10⁻²–10²)
  - train MSE: 차수가 오를수록 거의 단조 감소 **[추가]** (차수 d 모델은 d − 1 모델을 포함하므로 최소제곱 train 오차는 늘지 않음)
  - validate MSE: 차수 4–5 부근 최소 후 급증(차수 10 부근 약 10²)
  - 두 곡선의 간격 = 과적합 정도. log 축이라 위로 한 칸 = 10배
  - 차수 0–1에서 validate가 train보다 낮은 구간이 있다 **[추가]** → 14점짜리 작은 세트에서는 우연 변동이 크다는 뜻
- 임계점: validate 최솟값(차수 4) = 선택점. 그 뒤 train–validate 간격이 벌어지기 시작 = 과적합 시작
- 모델과 연결: GNN에서는 x축이 "차수" 대신 "epoch"가 되고, 같은 U자를 보고 조기 종료 시점을 정한다(39쪽 결과 예의 validate MAE 곡선).

**[추가] 수식 보충**: 다항식 ŷ = Σ_{j=0..d} θⱼ xʲ → θ 개수 = d + 1. 차수 11이면 θ 12개로 train 14점에 거의 보간, 차수 13이면 θ 14개로 정확히 통과(train MSE = 0) 가능.

**연결**: ← 7쪽(과소적합 언급), 9쪽(학습) / → 14쪽(분할 방법), 23쪽(learning curve), 24쪽(과적합 vs 학습 불안정), 49쪽(규칙: test 성능으로 설정을 고르지 않음).
