| 분할 | 방법 | MAE [K] | 평균 σ [K] | 2σ 적중률 (이상 0.954) | Spearman(\|오차\|, σ) |

**읽을 것**
1. **가장 정확한 모델이 σ 는 가장 나쁘다** (덱 25쪽 logP 와 같은 결론). BGNN 은 MAE 최저인데 σ 가 실제 오차의 절반 수준(random 2σ 적중 0.77)이고, scaffold 에서는 σ 가 오히려 **줄어서**(28 → 14 K) 적중률 0.42 — 처음 보는 골격에서 더 자신만만해진다. 원인 [추가, 확인 안 한 추정]: BGNN 은 마지막 선형층 64개 가중치만 확률로 두므로 σ 는 분자 벡터 z 의 크기에만 따라가고, z 가 학습 분포 밖인지 알 방법이 없다. 또 손실의 MSE 항은 '표본 100개의 평균'에만 걸려 σ 를 키울 이유가 없고, σ 를 사전분포 쪽(1)으로 미는 것은 KL / 4,000 뿐이라 학습이 길수록 σ 가 조금씩 자란다. scaffold 는 조기 종료가 이른 에폭(44 에폭에서 멈춤)의 가중치로 되돌려 σ 가 더 작다는 설명과 맞는다.
2. **GP 가 적중률은 거의 이상적**(0.946 / 0.924)이지만 **Spearman 은 0.21 / 0.04** — σ 의 '크기'는 맞는데 '어느 분자가 더 틀릴지' 순위는 거의 못 맞힌다. 특히 scaffold 에서는 세 방법 모두 Spearman ≤ 0.09. 덱 24쪽 "적중률만 보면 속는다"의 mp 판.
3. mp 에서 σ 순위가 약한 이유 [추가, 가설]: GP σ 는 **학습 분자와의 닮음**만 본다(4절: 유사도와 Spearman −0.89). 그런데 mp 오차의 큰 몫은 닮은 분자가 있어도 생긴다 — 결정 패킹·대칭(1주차 Mirex, 쿼터페닐)과 측정 잡음(1주차 데이터 카드: 반복 측정 4,679종 중 86종이 50 K 이상 차이). 이건 '닮음'으로 안 보이는 오차다.
4. 세 방법이 같은 분자를 불확실하다고 보나: Spearman(σ_RF, σ_GP) = 0.47, (σ_BGNN, σ_GP) = 0.12 → BGNN σ 는 다른 둘과 거의 무관.

## 2. 재보정 (README 여유 과제 D, validate 로 배율 c)

c = validate 에서 |오차| / 2σ 의 95.4 백분위 → test 에 σ × c 적용.

| 분할 | 방법 | c | validate 적중 (전) | test 적중 (전 → 후) | 재보정 후 평균 σ [K] |
|---|---|---|---|---|---|
| random | RF | 1.28 | 0.908 | 0.902 → 0.966 | 62.7 |
| random | GP | 1.04 | 0.942 | 0.946 → 0.960 | 52.0 |
| scaffold | RF | 1.52 | 0.860 | 0.886 → **0.958** | 89.1 |
| scaffold | GP | 1.12 | 0.926 | 0.924 → **0.946** | 60.5 |

- 재보정으로 **적중률은 고쳐진다** (네 경우 모두 0.946–0.966). **Spearman 은 그대로** — c 는 모든 σ 를 같은 배율로 키울 뿐 순위를 못 바꾼다 (덱 24쪽).
- BGNN 은 빠짐: `train.run()` 이 모델 객체도 validate 예측도 돌려주지 않는다. 0.954 에서 **가장 먼 방법이 BGNN** 이므로 원래 과제 D 의 대상은 BGNN 이다 → 다음에 할 것: `train.py` 의 `predict(model, loaders['validate'], …)` 결과를 CSV 로 저장하는 [추가] 한 줄 (원본 파일은 고치지 않고 감싸기). test 만 보고 추측하면: 0.42 → 0.954 에는 c ≈ 3–4 가 필요할 것으로 보이나 **validate 로 재야 함**.
- 재보정 후 σ 60–90 K = 기준선 MAE(75–80 K) 수준 → σ 로 고를 수 있는 분자가 거의 없다는 뜻이기도 하다.

## 3. 우연 vs 지식 불확실성 (GP 분해)

| | random | scaffold |
|---|---|---|
| GP 잡음 σ (우연, WhiteKernel) | **23.4 K** | 22.3 K |
| test 평균 전체 σ | 50.1 K | 54.2 K |
| test 평균 지식 σ = √(σ² − 잡음²) | 44.0 K | – |
| 학습된 커널 | 0.754² · Tanimoto + White(0.0659) | 0.73² · Tanimoto + White(0.0581) |

- 잡음 σ ≈ 23 K 는 데이터를 더 모아도 줄지 않는 몫의 GP 추정값. 1주차 결과 300–450 K 구간 MAE ≈ 27–30 K, GIN 전체 MAE 36 K 와 비교하면 **오차의 상당 부분이 하한(잡음)에 가깝다** [추가 해석, 정확한 비교는 아님 — 잡음 σ 는 표준편차, MAE 는 평균 절대값. 정규분포면 MAE ≈ 0.8σ ≈ 19 K].
- 커널 값은 marginal likelihood 로 자동 결정된 것 = 이 실습에서 유일하게 '자동 튜닝'된 하이퍼파라미터.
