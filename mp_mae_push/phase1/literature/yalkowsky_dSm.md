# Yalkowsky 계열 융해 엔트로피 식 (T4용)

조회일 2026-11-20.

## 확인 수준에 대한 경고

**원 논문 본문은 한 편도 열지 못했다.** Dannenfelser & Yalkowsky 1996, Jain 외 2004(2편), Jain & Yalkowsky 2006, Lian & Yalkowsky 2014는 모두 유료 논문이고, 같은 연구실의 공개 학위논문이 있는 repository.arizona.edu는 네트워크 허용 목록 밖이라 접근이 차단됐다. 아래 식의 **형태**와 **τ의 정의**는 2차 출처(같은 연구실 학위논문과 후속 리뷰의 검색 발췌) 세 곳이 서로 일치해 신뢰할 만하다. **계수 2.435와 2.85가 각각 어느 논문의 값인지**와 **ΔHm 기 기여값**은 미확인이다. T4-(b)에서 계수를 학습 가능하게 두는 설계라면 이 미확인은 초기값에만 영향을 준다.

## 식 (2차 출처 일치)

- 융해 엔트로피: ΔSm = 50 − R ln σ + R ln φ  [J/(K·mol)], R = 8.314 J/(K·mol)
- 유연성: φ = c^τ, τ = SP3 + 0.5·SP2 + 0.5·RING − 1
- 따라서 ΔSm = 50 − R ln σ + (R ln c)·τ
  - c = 2.435이면 τ 계수 7.4 J/(K·mol)
  - c = 2.85이면 τ 계수 8.71 J/(K·mol)
  - 상용로그로 쓰면 R ln σ = 19.14·log10 σ
- 녹는점: Tm = ΔHm / ΔSm, ΔHm = Σ nᵢ·mᵢ (기 기여 합)
- 예시(이 문서에서 계산): 벤젠(σ = 12, τ = 0) ΔSm = 29.3 J/(K·mol). σ = 1, τ = 5인 사슬형 분자는 c = 2.435에서 87.0, c = 2.85에서 93.5 J/(K·mol). 두 버전의 차이는 τ 1당 1.31 J/(K·mol)로, 유연한 분자일수록 벌어진다.

## T4 구현에 대한 제안 (조사자의 의견, 문헌 사실 아님)

1. T4-(b)의 구조 모델은 ΔSm = a − R ln σ + b·τ로 두고 a = 50, b = 7.4–8.71를 초기값으로 해 학습시킨다. 두 버전의 차이가 b 하나로 흡수되므로 미확인 계수가 결과를 좌우하지 않는다.
2. τ는 RDKit으로 직접 셀 수 있다: 고리 밖·차수 2 이상인 sp3 무거운 원자 수 + 0.5 × 같은 조건의 sp2 원자 수 + 0.5 × 융합 고리계 수 − 1. 음수는 0으로 자르는 안과 그대로 두는 안을 둘 다 특징으로 넣어 validation으로 고른다. RING을 세는 두 방식(단일 결합으로 이어진 고리를 합치는지)도 마찬가지다.
3. σ는 회전 조작만 세는 외부 대칭수다. 그래프 자기동형 수는 반사를 포함해 과대 추정하므로 3D conformer 점군에서 구하는 값과 구분해 기록한다. 원뿔·원통·구형의 유효값(10, 20, 100)은 우리 데이터의 작은 분자(메테인, CO2 등)에만 해당한다.
4. 편심도 ε을 넣은 확장(Johnson & Yalkowsky 2005)은 강직한 다환 방향족 117종에서 녹는점 오차를 90 K에서 43 K로 줄였다고 보고한다. 550 K 초과 구간의 과소 예측이 우리 문제이므로 ε에 해당하는 형상 특징(관성 주축 비, 상자 부피 비)을 T4 후보에 포함할 근거가 된다. 계수는 미확인이므로 특징으로만 쓴다.
5. Yalkowsky 방식 자체의 정확도는 2,200종에서 평균 절대 오차 30.1 K(Jain & Yalkowsky 2006)로 우리 기준선 27.5 K보다 나쁘다. 이 식은 단독 예측기가 아니라 유도 편향(특징 또는 readout 구조)으로 쓰는 것이 맞다.
