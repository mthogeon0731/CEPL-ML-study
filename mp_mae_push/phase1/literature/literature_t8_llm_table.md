# 자연어·LLM 표현으로 분자 물성을 회귀한 연구 (T8 근거 문헌)

조회일 2026-11-20. 본표 12편 + 기억 누설·표현 선호 보조 5편. 수치는 원문·초록에서 확인한 것만 적었다. 프리프린트는 표시했다.

## 한눈에 보는 결론

- **데이터가 1만 개를 넘는 회귀에서 대형 LLM(M4)이 GBDT·GNN을 이긴 사례는 확인한 문헌에 없다.** LLM 미세조정의 강점은 표본 수십–수백 개 영역에 한정되고(Jablonka 2024), 표본이 늘면 기존 ML이 따라잡거나 앞선다(Jablonka 2024; Jacobs 2024; Gupta 2025; Zhong 2024).
- **녹는점을 직접 다룬 LLM 결과는 두 건뿐이고 둘 다 약하다.** 27.5만 분자 고/저 분류에서 미세조정 정확도 66–69 %, zero-shot은 무작위 수준(Van Herck 2025). 고분자 Tm 회귀에서는 LLM이 전용 모델보다 열세(Gupta 2025). 유기 분자 녹는점을 LLM으로 **회귀**해 GBDT와 비교한 논문은 찾지 못했다.
- **LLM이 쓴 서술(N3)로 큰 이득을 보고한 두 편은 누설 통제가 없다.** 이득은 ESOL·FreeSolv 같은 작고 유명한 세트에 몰려 있고 Lipophilicity에서는 GNN보다 나쁘다(Balaji 2023; Qian 2023). 서술에 물성이 들어간다는 점이 원문에 적혀 있다.
- **가장 근거가 좋은 경로는 M2(규칙 → 특징)와 화학 특화 임베딩 + head다.** LLM4SD는 scaffold 분할에서 기준선을 넘었고(Zheng 2025), 녹는점에서는 ChemBERTa + MoLFormer 임베딩 + TabM이 MAE 26.75 K를 냈다(Dubonos 2026, 11.8만 분자; MP 문헌 표 8번).
- **이름(N1)은 zero/few-shot에서만 SMILES보다 유리하다.** 미세조정하면 SMILES가 같거나 낫다(Van Herck 2025: 녹는점 69 % vs 66 %, 단량체 76 % vs 57 %).

## 우리 과제에 대한 시사점

조건: 학습 약 1.6만 분자, 녹는점 회귀, CPU만 사용. N1 이름 / N2 템플릿 / N3 LLM 서술 × M1 임베딩 + head / M2 규칙 → 특징 / M3 소형 LM 미세조정 / M4 대형 LLM.

1. **M2(LLM 규칙 → RDKit 특징)가 비용 대비 가장 유망하다.** LLM 호출이 분자 수와 무관해 사실상 무료이고, scaffold 분할에서 기준선을 넘은 유일한 LLM 방식이다(Zheng 2025). 다만 우리 기준선은 이미 RDKit 기술자 217개를 쓰므로 새 정보가 얼마나 남는지는 불확실하다. 참고 팀의 결정 특징 13개가 튜닝 모델에서 −0.25 K(유의하지 않음)였다는 점이 상한을 시사한다.
2. **N2(템플릿) × M1/M3은 누설 위험이 0인 텍스트 경로의 기준선이다.** 규칙 기반 서술 + 소형 언어모델이 GNN과 같은 급이라는 선례가 결정에서 있다(Rubungo 2023). 정보 내용이 기술자와 같으므로 정확도 이득보다는 “텍스트로 바꿔도 잃지 않는가”를 재는 대조군으로 쓴다.
3. **M1은 임베딩 모델 선택이 결과를 좌우한다.** 범용 임베딩에 SMILES를 넣으면 약하고(Sadeghi 2024: GPT 임베딩 전 과제 열세), 화학 데이터로 학습한 모델이어야 쓸모가 있다(Kristiadi 2024). 따라서 범용 소형 임베딩에는 N1·N2 텍스트를, ChemBERTa·MoLFormer에는 SMILES를 넣어 비교한다. 후자는 녹는점에서 GBDT 수준에 도달한 직접 선례가 있다(Dubonos 2026).
4. **N1(IUPAC 이름) × M1은 싸게 해볼 만하지만 RDKit 217보다 나을 근거는 없다.** 이름 임베딩 + 커널 릿지가 LLM in-context보다 좋았다는 결과는 있으나(Ramos 2023, ESOL), 미세조정 비교에서는 이름이 SMILES보다 나쁘다(Van Herck 2025, 녹는점 분류).
5. **N3(LLM 서술) × M3은 문헌상 가장 큰 숫자를 보였지만 가장 의심스럽다.** 물성 금지 필터와 기억 점검을 통과해야 결과로 쓸 수 있고, 19,945분자 생성 비용이 든다(비용 가정 문서 참조). N2와 같은 head에서 짝지어 비교해 “LLM이 쓴 문장이 템플릿보다 얼마나 더 주는가”만 본다.
6. **M4(대형 LLM 미세조정·few-shot)는 1.6만 학습 규모에서 XGBoost 27.5 K를 넘을 가능성이 낮다.** 1,000·4,000개 파일럿으로 학습 곡선의 기울기만 확인하고, QM9에서 보고된 멱법칙 지수 −0.74(Jacobs 2024)보다 완만하면 중단한다.
7. **기억 누설 점검 설계의 선례**: (i) 이름만 주는 zero-shot 질의로 회상률 기준선(Van Herck 2025는 50 %로 무작위 수준), (ii) 유효숫자 자릿수 일치 통계와 분자-무관 기준(Busch 2026, arXiv 2609.05381), (iii) 이름·물성명을 가리는 단계적 blinding과 양성·음성 대조(Busch 2026, JCIM), (iv) 이름 빈도 층화(Microsoft Research 2023), (v) random과 scaffold의 격차 비교(Qian 2023에서 random 이득이 scaffold에서 뒤집힘). Bradley 데이터는 2014년부터 공개돼 있어 사전학습 노출을 전제로 해야 한다(Bordt 2024).
