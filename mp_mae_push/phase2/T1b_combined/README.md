# T1b 결합 모델 트랙 (2단계 2차) — 2026-11-21

Bradley Open MP 녹는점(K). 모든 수치는 **validation**(random n 1,995 / scaffold n 1,994; 중복 제거 1,922 / 1,986) 또는 train 5-fold OOF에서 나왔다. test는 보지 않았다. 차이는 MAE(새 모델) − MAE(기준)이며, 음수가 개선이다. CI는 짝지은 부트스트랩 2,000회의 95 % 구간이다.

## 결론

1. **최선 결합은 LightGBM lgb_r1 + F0+F3+F5(357열)이다.** 두 분할, 두 기준(전체·중복 제거) 모두에서 1단계 비교 대상 중 1위였다. validation MAE(seed 3 평균 예측)는 random 25.359 K, scaffold 35.238 K이다. 같은 모델 F0 대비 random −0.79 [−1.16, −0.42], scaffold −0.73 [−1.24, −0.22]이다. 기준선(XGB 600그루) 대비는 random −2.25 [−2.74, −1.77], scaffold −1.11 [−1.71, −0.48]이다.
2. **F5(LLM 규칙)가 이득의 대부분을 낸다.** F0+F5 대비 F3(물리·결정)의 추가분은 두 분할 모두 유의하지 않다: random −0.11 [−0.35, +0.13], scaffold −0.21 [−0.58, +0.16]. F3에는 3D 배좌 계산 비용이 들므로 **F0+F5를 경제안 후보로 남긴다**.
3. **H06 Yalkowsky 구조(Tm 척도 손실)는 전체 MAE를 바꾸지 못했다.** train OOF + validation을 합쳤을 때 random +0.08 [−0.01, +0.18], scaffold −0.07 [−0.18, +0.06]이다. >550 K 구간의 음의 쏠림은 유의하게 줄었다(random +1.7 K, scaffold +5.3 K). 그 구간 MAE도 −1.09 / −3.76 K로 줄었다. 대신 y < 250 K 구간 MAE는 +0.96 / +1.30 K로 유의하게 나빠졌다. 고대칭 부분집합의 변화는 유의하지 않다. 참고 팀은 ΔHm 척도 손실로 scaffold가 38.3 K까지 나빠졌다. Tm 척도 손실을 쓰자 그런 악화는 없었다(scaffold validation 35.194 K). 그러나 쏠림은 크게 남았다(>550 K 평균 잔차 −62 / −69 K). **단독 채택은 하지 않고 앙상블 재료로 넘긴다.**
4. **H19 극단 구간 가중치 4는 채택하지 않는다.** random seed 0만 돌렸다. 전체 MAE는 +0.20 [−0.10, +0.51]로 점추정이 나빠졌다. 극단 구간은 좋아졌다(<250 K −2.13, >550 K −4.18). 대신 250–350 K가 +1.20 [+0.69, +1.75] 나빠졌다. 사전 규칙(전체가 나빠지면 채택하지 않음)에 따라 기각했다. 이 판정은 1개 변형, 1개 분할, seed 1개에 근거하므로 잠정이다.

## 2. H06 Yalkowsky 구조 본 실행

- 구조: GBDT 출력 h는 ΔHm[kJ/mol]이다. ΔSm은 S = max(a − R ln σ + R·b·τ, 10)으로 두고, Tm = 1000·h/S로 예측한다. 목적함수는 Tm 척도 Huber(δ 60 K)다: grad = k·clip(k·h − y, ±60), hess = k², k = 1000/S. init_score는 median(y)·S/1000이다. 하이퍼파라미터는 lgb_r1(6 스레드)과 같다. 특징은 F0+F3+F5다. σ는 sigma3d_max_log이며, NaN 9행은 σ = 1로 두었다. τ는 tau_clip0다.
- (a, b) 선택은 train 안 내부 85/15 분할(T1 규칙)에서 했고 validation은 쓰지 않았다. 격자는 a ∈ {40, 50, 65} × c ∈ {2.435, 2.85}(b = ln c)였다. 3D σ 최선 조합에서 2D σ(sigma2d_log)도 한 번 돌렸다. 대조(S ≡ 상수 = Tm 직접 회귀)도 같은 기계로 넣었다. 비용 때문에 격자는 learning_rate × 3 대리 적합(seed 0, 조기 종료 200)으로 돌렸다.

| 분할 | 대조 내부 MAE | 선택 (a, c, σ) | 선택 내부 MAE | 2D σ 대안 | 본 lr 내부 조기 종료 best_iter → 나무 수 |
|---|---|---|---|---|---|
| random | 26.483 | 65, 2.435, 3D | 26.392 | 26.510 | 3,900 → 4,588 |
| scaffold | 31.901 | 40, 2.435, 3D | 31.437 | 31.716 | 3,018 → 3,304 |

## 6. 실패하거나 채택하지 않은 시도

- H06 Yalkowsky 구조: 전체 MAE 이득이 없다(위 2절). 2D σ 대안은 두 분할 모두 3D σ보다 내부 MAE가 나빴다(26.510 vs 26.392, 31.716 vs 31.437). c = 2.85는 두 분할 모두 선택되지 않았다. 격자 안의 차이(random 0.26, scaffold 0.59 K)는 seed 1개 대리 적합이라 잡음과 구분이 어렵다.
- H19 w4: 전체 MAE 점추정이 나빠져 기각했다(잠정).
- F0+F3(F5 없이): random에서 F0 대비 유의하지 않다(−0.17 [−0.48, +0.14]).

## 7. 다음 단계(앙상블)에 넘길 것

- 앙상블 멤버 1순위는 lgb_F0F3F5 validation + OOF다. H06은 >550 K 쪽에서 다른 오차를 낸다. 단순 평균만으로 scaffold −0.18 K(경계)이므로 가중치는 OOF에서 정할 것을 권한다.
- lgb_F0F5는 3D 배좌 없이 쓰는 경제안이다. OOF가 없어 스태킹 메타학습에는 그대로 쓸 수 없다. 필요하면 1.0 core-h 정도를 더 들여 만든다.
- >550 K 음의 쏠림(−62 ~ −74 K)은 결합·구조·가중으로 일부만 줄었다. 위험–커버리지(목표 C)에서 이 구간을 낮은 신뢰도로 걸러야 한다.

## 편차 (계획과 다르게 한 것)

1. **XGBoost(xgb_r1) 결합 생략**: 예산(7 core-h) 때문에 특징 묶음 결합은 LightGBM lgb_r1로만 했다. xgb_r1 × {F0+F3, F0+F5, F0+F3+F5}의 18개 적합(추정 3–4 core-h)은 하지 않았다. 근거는 두 가지다. T1에서 F0 기준 lgb_r1이 xgb_r1보다 validation에서 같거나 낫고, 적합 비용은 절반이었다.
2. **F0 팔은 T1 예측 재사용**: lgb_r1 F0와 xgb_r1 F0는 다시 적합하지 않았다. T1 재적합 seed 0–2 평균 예측을 썼다. T1 LightGBM은 8 스레드였고, 이 트랙은 6 스레드(동시 실행 GIN 때문)다. 6 스레드 seed 0 재적합 MAE는 26.269다. T1의 seed별 값이 없어 스레드 효과와 seed 잡음을 나눌 수 없다.
3. **나무 수 재결정 안 함**: 열이 늘었지만 1단계는 T1 나무 수를 그대로 썼다(허용 범위).
4. **H06 설계 변경**:
   - (a) 손실은 권장한 Tm 척도 제곱 대신 Tm 척도 Huber(δ 60)를 썼다. 비교 기준 lgb_r1의 손실과 맞춰 구조 효과만 보려는 것이다.
   - (b) (a, b)를 연속 학습하지 않고 격자에서 골랐다. 격자는 lr × 3, seed 1개 대리 적합이다.
   - (c) S 하한은 10 J/(K·mol)이다. 하한에 걸린 행은 1개였다(5.0e−5 비율, a = 40일 때).
   - (d) H06의 나무 수는 자기 내부 조기 종료로 정했다(4,588 / 3,304). 비교 기준은 T1 나무 수(3,688 / 2,978)다. 나무 수 차이가 비교에 섞여 있다.
   - (e) H06 비용은 3.29 core-h로 배정 2 core-h를 1.29 넘었다. OOF(1.29 core-h)가 예상보다 비쌌다. 그만큼 H19를 줄였다.
5. **H19 축소**: 계획은 가중치 2, 4, oversampling × 두 분할(× seed)이었다. 실제로는 w4, random, seed 0의 1개 적합만 했다. w2, os2, scaffold 전체는 하지 않았다. H19 결론은 잠정이다.
6. **OOF는 seed 0 하나**: OOF는 lgb_F0F3F5와 H06에만 있다. lgb_F0F5에는 없다. 부분집합 합침 판정은 validation(seed 3 평균)과 OOF(seed 0)를 섞은 것이다.
7. **재현 스크립트 실행 검증 생략**: train_candidate.py는 1단계 적합과 같은 함수·행 순서·나무 수를 쓰도록 짰다. 그러나 예산 때문에 다시 돌려 예측이 일치하는지는 확인하지 않았다.
8. **물려받은 단서**: F5 규칙을 만든 프롬프트 예시가 1단계 train OOF 오차 분해를 참고했다(T8 기록). validation·test 라벨은 쓰지 않았지만, 같은 데이터에서 나온 정보가 특징 설계에 들어갔다.
