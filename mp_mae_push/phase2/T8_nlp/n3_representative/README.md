# T8 N3 보강 — 무작위 대표 표본으로 N3(LLM 구조 서술) 재평가 (random 분할)

작성 2026-11-21. random 분할만 다룬다(scaffold는 앞 T8 README 12.2절의 잠정 결과로 남김). test는 쓰지 않았다.

## 편차
1. **train 새 표본 1,786개(목표 1,800, −14)**. 호출 상한 3,450건에서 validation 1차 1,636 + 재시도 12를 쓰고 남은 1,802건 중 16건을 train 재시도 여유로 남겼다(규칙은 호출 전 {{artifact:8beceb04-03f9-4871-9266-02d2086f5025}}에 고정). seed 0 순열의 앞부분이라 무작위 표본이다. 최종 성공 1,785개.
2. **validation N3 보유 1,993 / 1,995**(행 11243, 11572는 1차·재시도 모두 max_tokens 400에서 잘림). 그래서 비교의 '전체'는 n 1,993, '중복 제거'는 n 1,920(지시의 1,995 / 1,922보다 2개 적음)이다. 모든 표현을 같은 1,993행에서 비교했다.
3. **금지어 필터는 원 코드가 아니라 재구현**이다. 앞 생성 스크립트가 아티팩트로 남아 있지 않았다(지정된 0a6240d5는 평가 스크립트 run_n3_partial.py). 앞 README의 필터 정의대로 정규식을 다시 만들었고, 기존 3,600건의 reject_prop_word 플래그를 15/15, 3,585/3,585 그대로 재현했다. 지시문은 원문 그대로 썼다.
4. **XGBoost seed는 0, 1, 2**(지시대로). 앞 T8 평가 모듈은 (42, 0, 1)을 썼다. 앞 잠정 결과와의 대조에 미세한 차이가 생길 수 있다.
5. 지시에 없던 대조를 추가했다: M2(RDKit217+F5) − RDKit217(README 11절이 요구하는 기술자 계열 층화 대조), RDKit217+N2 bge(대조), 그리고 validation을 '기존 확보분 359 / 새 1,634'로 나눈 Δ.
6. 생성 단계 일부 비용(캐시 쓰기 19,548토큰)은 단가 가정(0.20 USD/1M, 입력가의 2배)에 기댄다(0.004 USD).

## 2. 비교 설계
- 학습 집합 (i) **ALL** = N3 있는 train 전부 5,110(기존 비대표 3,325 + 새 1,785), (ii) **NEW** = 새 무작위 1,785만.
- 같은 학습 집합·같은 분자로 RDKit217, M2, N2(MiniLM, bge-small), N3(같은 두 모델), RDKit217+N3, RDKit217+N2 bge를 적합. head: XGBoost(BASE_XGB, n_jobs 8, seed 0·1·2 예측 평균), Ridge(t8eval RidgeHead, alpha는 train 안 5-fold CV).

## 3. 앞의 잠정 결과와 같은가
- 앞 잠정: N3 bge − N2 bge (XGBoost, random) **+4.67 [+2.25, +7.12] K** — 비대표 확보분 train 3,325, validation 359.
- 이번: ALL **+3.79 [+2.42, +5.19] K**, 대표 표본 NEW **+3.72 [+2.39, +5.04] K** (validation 1,993). 같은 359분자만 보면 ALL +3.50 [+1.03, +6.10] K.
- **방향과 유의성은 같고 크기는 약 1 K 작다**(CI가 서로 겹친다). 대표 표본(NEW)과 비대표 표본을 섞은 ALL이 거의 같은 값을 주므로, 앞 결과의 결론은 표본 비대표성 때문이 아니었다. MiniLM, Ridge에서도 N3 − N2는 +2.3 ~ +4.2 K이고 8개 조합 모두 CI 하한이 0보다 크다.
- RDKit217+N3 − RDKit217: 앞 잠정 +2.33 [+1.20, +3.53](bge, XGBoost) → 이번 ALL +1.95 [+1.33, +2.57] K. 역시 같은 결론(XGBoost에서는 붙이면 나빠짐, Ridge에서는 0 근처).

Ridge에서는 기술자 대조(M2 − RDKit217)에도 양의 I가 있어, 유명/희귀 층 차이 일부는 텍스트 고유가 아닌 분자 분포 차이로 보인다.

## 5. 결론 (3줄)
1. 대표 표본으로 다시 해도 **LLM 서술(N3)은 템플릿 서술(N2)보다 나쁘다**: bge · XGBoost 기준 +3.7 ~ +3.8 K(CI 0 제외), 앞 잠정 +4.67 K와 방향·유의성이 같고 크기만 약 1 K 작다.
2. N3는 RDKit217보다 XGBoost에서 +11 ~ +14 K, Ridge에서 +5.5 ~ +7 K 나쁘고, **RDKit217에 붙여도 XGBoost에서 +1.5 ~ +2.0 K 나빠지며** Ridge에서는 차이가 없다 — 앙상블 후보 근거가 없다.
3. 유명도 층화에서 기억 효과 증거는 없다(유명 분자에서 N3가 오히려 더 나쁨). N3는 0.73 USD를 더 써도 성능 이득이 없으므로 **T8 후보에서 제외** 판정을 유지한다.
