# 2단계 사전 고정 규약 (2026-11-20, 실행 전 고정)

이 문서는 2단계 실행 전에 고정한다. 실행 중 바꿔야 하면 바꾼 날짜·이유·영향을 문서 끝 '변경 기록'에 남기고, 이미 본 validation 결과가 변경의 이유가 되었는지 함께 적는다. test는 3단계 최종 후보(3개 이하)에만 한 번 쓴다.

## 1. 공통 규약

1. 분할은 `splits/random.csv`, `splits/scaffold.csv`만 쓴다. 세트 안 순서는 `pos` 열을 따른다(`mpcommon.load_split`).
2. 하이퍼파라미터·특징·가중치·보정 배율·앙상블 가중치·seed는 validation 또는 train 안 5-fold CV로만 정한다. test로 고르거나 조기 종료하지 않는다.
3. XGBoost는 `n_jobs=8`로 고정한다(스레드 수가 적합 결과를 바꾼다). 다른 라이브러리도 스레드 수를 ledger `params`에 적는다.
4. 확률적 모델은 seed 3개 이상, 평균 ± SD로 보고한다.
5. 트랙마다 자기 폴더 `T<번호>_<이름>/`에만 쓴다. 실행 하나당 `ledger.csv` 한 줄(열은 `mpcommon.LEDGER_COLS`). 에너지는 P_cpu 25 W로 환산한다(`mpcommon` 기본값).
6. validation 예측은 두 분할 모두 `row, y, pred` 열로 저장한다(앙상블용). 최종 후보만 test 예측을 만든다.
7. 금지: 외부 MP 값을 특징으로 쓰기, test 라벨을 모델 예측과 비교해 고치기, test로 선택하기, 측정된 보조 물성값을 mp 모델 특징으로 쓰기.

## 2. 중복 제거 validation·test와 두 기준 순위 (사용자 수정 4)

- 겹침 판정은 InChIKey 첫 블록(14자, 입체 무시)이다. 행 목록: `prereg/dedup_rows_random.csv`, `prereg/dedup_rows_scaffold.csv` (`overlap` = 1이면 제외).
  - validation: 첫 블록이 train에 있으면 제외.
  - test: 첫 블록이 train 또는 validation에 있으면 제외.

| 분할 | 세트 | n | 겹침 | 중복 제거 n |
|---|---|---|---|---|
| random | validation | 1,995 | 73 | 1,922 |
| random | test | 1,995 | 99 | 1,896 |
| scaffold | validation | 1,994 | 8 | 1,986 |
| scaffold | test | 1,995 | 11 | 1,984 |

- 모든 후보의 순위를 전체 기준과 중복 제거 기준으로 각각 내고, 두 순위가 다른 후보에 표시한다. validation 단계의 후보 선정은 두 순위를 함께 보고, 선정 근거로 어느 쪽을 썼는지 적는다.
- 최근접 이웃 계열(O2 Tanimoto kNN과 그것이 들어간 앙상블)은 중복 제거 기준을 주 기준으로 쓴다. 그 이득이 겹치는 분자에서만 나오면 "근접 중복 활용"으로 따로 표시한다.

## 3. 보조 물성 누설 방지 (사용자 수정 1)

- 보조 물성 파일과 mp validation·test의 겹침 (`prereg/aux_overlap_counts.csv`; random test, n 1,995):

| 보조 물성 | 보조 행 수 | InChIKey 전체 일치 | 첫 블록 일치 |
|---|---|---|---|
| logSolubility | 11,172 | 412 | 442 |
| logP | 14,031 | 411 | 447 |
| density | 8,746 | 483 | 521 |
| logPvap | 3,092 | 219 | 230 |
| bp | 2,159 | 147 | 152 |

  사용자가 알려 준 수치(406 / 405 / 479 / 218 / 147)와 조금 다르다. 일치 판정 기준(SMILES 대 InChIKey)의 차이로 보이며, 더 보수적인 첫 블록 기준으로 제외한다.
- 규칙:
  1. 보조 모델 학습 데이터에서 첫 블록이 두 분할의 mp validation·test 중 하나에라도 있는 행을 지운다(`prereg/aux_exclusion_keys.csv`). 지워지는 행: logSolubility 1,621, logP 1,355, density 1,457, logPvap 692, bp 337.
  2. mp train 행에 붙이는 보조 예측값은 보조 모델의 out-of-fold 예측만 쓴다. 보조 데이터에 있는 mp train 분자도 측정값을 쓰지 않는다.
  3. mp validation·test 행에는 위 1로 학습한 보조 모델의 예측값을 쓴다.
  4. logSolubility 특징은 일반 용해도 식(logS ≈ 0.5 − 0.01(mp[°C] − 25) − logP)으로 mp와 직접 연결되므로 따로 넣고 빼서 효과를 분리 보고한다. logS 보조 모델이 실질적으로 mp를 되돌려 주는지 확인하려고, logS 예측값과 mp 라벨의 상관을 mp train OOF와 validation에서 함께 보고한다.
  5. 다중 작업 모델(공유 인코더)을 쓰는 경우에도 같은 제외 규칙을 따른다.

## 4. 외부 MP 데이터 처리 규칙 (사용자 수정 5)

파싱 전에 고정한다. 파일의 필드 구성이 아래 가정과 다르면 규칙을 바꾸지 말고, 해당 필드를 처리할 수 없다고 기록한 뒤 그 행을 제외한다.

| 항목 | 규칙 |
|---|---|
| 대상 | Tetko 2016 특허 세트 `melting_point.sdf`(figshare 10.6084/m9.figshare.2007426, 637,981,904 B)와 Enamine 세트(OCHEM; 접근 실패 시 생략하고 사유 기록). 특허 세트의 `pyrolysis_point.sdf`(분해점)는 쓰지 않는다 |
| 분해 표지 | 분해(decomposition, dec., pyrolysis) 표지가 붙은 기록은 제외 |
| 부등호 값 | `>`, `<`, `≥`, `≤`, `~`, `ca.`가 붙은 값은 제외 |
| 범위 값 | `a–b` 형식은 폭 ≤ 5 K이면 중앙값, 폭 > 5 K이면 제외 |
| 단위 | °C는 +273.15로 K 변환. 단위가 불명확하면 제외 |
| 값 범위 | 50–800 K 밖이면 제외 |
| 구조 | RDKit으로 읽히지 않거나, 여러 조각(염·혼합물, `.` 포함)이거나, 무거운 원자 > 100이면 제외 |
| 한 분자의 여러 기록 | canonical SMILES별 중앙값. 기록 범위가 50 K를 넘으면 그 분자 제외 |
| mp와의 겹침 | 첫 블록이 두 분할의 mp validation·test에 있으면 제외(`prereg/aux_exclusion_keys.csv`). mp train에 있는 분자도 학습에서 제외해 mp 라벨을 유지한다. 단, 일치도(외부 값과 mp 라벨의 차이)는 진단용으로 따로 보고한다 |
| 기록 | 단계마다 남은 행 수, 규칙별 제외 수, 라이선스(figshare 표기 CC0, 논문 본문 표기 CC-BY로 불일치 → 인용 필수로 간주; Enamine은 OCHEM 약관 확인), 다운로드 일시·sha256 |
| 효과 비교 | 외부 데이터 추가량별 validation MAE를 1단계 학습 곡선이 같은 n_train에서 예측한 값과 나란히 비교한다. 예측은 `phase1/tables/learning_curve_extrap.csv`의 4개 모형(낙관–보수) 범위로 준다 |

## 5. 라벨 정제 규칙 (train에만 적용, test 라벨은 원본 유지)

- R1 여러 조각(`.` 포함) 분자: train에서 제외(전체 데이터에 1개).
- R2 반복측정 범위 ≥ 50 K인 분자: train에서 제외하는 변형과 가중치를 낮추는 변형(가중치 1/(1 + 범위/10 K)) 두 가지(`phase1/tables/mp_replicate_stats.csv`).
- R3 '구조상 의심 라벨'(사슬형, 수소결합 주개 0, 전하 없음, 무거운 원자 ≤ 15, 라벨 ≥ 400 K): 1단계 OOF 상위 오차를 보고 만든 규칙이라 모델 정보가 섞여 있다. 탐색적 변형으로만 쓰고 그렇게 표시한다.

## 6. LLM 호출 한도 (사용자 승인 조건)

- 분자 단위 LLM 호출은 N3 500분자 파일럿까지다. N3 전체(19,945건), zero-shot 회상률 점검, M4 few-shot은 파일럿의 실측 토큰과 비용을 보고한 뒤 다시 승인받는다.
- M2(규칙 제안)는 분자 단위가 아닌 호출 몇 회라 이 한도 밖이다. 규칙 제안 시 test 분자·라벨은 보여주지 않는다.
- 분자 단위 호출의 기본 모델은 소형(Haiku급)이다. 생성 텍스트에 숫자 + 물성 단위(°C, K, g/cm³, mmHg 등) 패턴이 있으면 걸러 내고 탈락률을 기록한다.

## 7. 목표 C 정의 (test를 보기 전에 고정)

- 위험–커버리지: 신뢰도 점수(앙상블 분산, 최근접 train Tanimoto, 반복측정 수를 입력으로 하는 오차 예측 메타모델)를 validation 교차 적합으로 만든다. validation에서 MAE ≤ 10 K를 만족하는 가장 낮은 신뢰도 기준을 고정하고, test에는 그 기준을 한 번만 적용해 커버리지와 MAE를 보고한다.
- 부분집합: `phase1/tables/mol_flags.csv`의 계열 표지와 1단계 MP 구간(< 250, 250–350, 350–450, 450–550, > 550 K). 부분집합별 MAE ≤ 10 K 여부는 validation 결과와 test 결과를 나란히 보고한다.
