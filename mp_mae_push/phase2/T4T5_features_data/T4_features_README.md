## 결론

1. **F3(물리·결정 특징 39열)은 scaffold에서 유효, random에서는 경계선.** F0+F3 vs F0(seed 3): scaffold −0.93 [−1.45, −0.42], random −0.30 [−0.66, +0.04]. train 5-fold OOF와 validation을 합친 판정(n 17,950)에서는 random −0.45 [−0.57, −0.33], 고대칭 계열(sym2d_high, n 1,881) −1.64 [−2.20, −1.11], > 550 K(n 451) −2.80 [−3.94, −1.68]로 모두 유의. 다만 > 550 K의 평균 편향은 −69.0 → −65.8 K로 거의 그대로라 평균 당김은 풀리지 않았다.

3. **H17 연쇄 특징은 random에서 이득 없음.** F0 대비(seed 3): 보조 4종(logS 제외) +0.05 [−0.26, +0.36], logS만 +0.02 [−0.15, +0.18], 5종 +0.24 [−0.05, +0.54]. scaffold에서는 보조 4종이 −0.41 [−0.77, −0.01](경계선). logS 예측값과 mp 라벨의 상관은 약하다(Pearson r: random train −0.21, val −0.23) → logS 보조 모델이 mp를 되돌려 주는 누설 징후는 없다.
4. **O4 표준화·H09 라벨 정제는 효과 없음**(모든 CI가 0 포함 또는 경계선). 표준화로 바뀐 행 1,681개, random +0.24 [−0.06, +0.53]. R2a(범위 ≥ 50 K 89행 제외)·R2b(가중치)·R3(30행 제외, 탐색적) 모두 random |Δ| ≤ 0.07 K.
