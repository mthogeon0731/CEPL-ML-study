# T5 외부 MP 데이터 — 트랙 보고 (H07)

작성 2026-11-21. 모델은 기준선 XGBoost(600그루, lr 0.05, depth 6, subsample 0.8, colsample 0.5, n_jobs=8) 고정, 특징은 RDKit 기술자 217개(F0). test 행 예측은 만들지 않았다. 모든 MAE는 validation, 단위 K, seed 42·43·44.

## 결론

1. **random 분할: 특허 데이터를 더하면 나빠진다.** 0.5배 +0.32 K에서 전체(19.5만 분자) +2.19 K까지 추가량에 비례해 악화(seed 평균 MAE 기준, F0 같은 seed 대비). 1단계 학습 곡선은 같은 n에서 −0.84 ~ −8.32 K 개선을 예측했다. → **본 학습에 쓰지 말 것**(PREREG 중단 기준: 이득 < 예측의 절반).
2. **scaffold 분할: 약 −0.6 ~ −1.0 K 개선, 추가량과 무관(평탄).** 0.5–4배는 '보수 예측의 절반' 기준을 넘지만 전체 추가는 못 넘고(−0.85 vs 기준 −1.10), 양을 늘려도 더 좋아지지 않는다. 개선은 Murcko scaffold가 외부 세트에 있는 validation 분자(889/1,994)에 몰려 있다(아래 표) — 외부 데이터가 scaffold 분할의 '새 골격' 조건을 부분적으로 깨기 때문이다.
3. 원인 진단: 특허 값 분포가 mp와 다르다(평균 426 vs 378 K, SD 59 vs 92 K; 저융점 액체가 거의 없음). random validation의 y < 300 K 부분집합 MAE가 26.1 K(F0) → 34.4 K(전체 추가)로 악화했다. 특허 세트와 mp의 분자 겹침은 64개뿐이라 라벨 일치도는 n 37로만 볼 수 있다(절대 차 중앙값 4.0 K, 평균 28.3 K; 잠정).
4. 라벨 품질: 같은 수(60,660)로 비교하면 '보고 범위 폭 ≤ 1 K' 기록이 무작위보다 random에서 −0.38 K [−0.66, −0.10] 낫다(scaffold는 +0.23 [−0.14, +0.58]로 차이 없음). 품질이 조금 도움이 되지만 분포 차이로 생기는 손해를 상쇄하지 못한다.
5. 다음 단계 제안: 원본 그대로 섞는 방식은 권하지 않는다. 시도한다면 (a) 출처 표지 특징 또는 외부 행 가중치 < 1, (b) 외부 데이터로 사전학습한 모델의 예측을 앙상블 구성원으로(scaffold 전용), (c) mp 분포에 맞춘 재표집. 이는 모델·결합 트랙의 일이다.
