## 방법론 평가
**강점 (가져올 것)**: 질문 하나 → 가설 셋 → 검증 → 요약표 구조, 분할별 정답 분포 표, 구간 잔차 + 95 % CI, readout의 물리 해석과 불가능한 예측 제시, 정답 섞기(y-randomization)로 해석 깊이 결정, 그룹 순열, IG 기준점 함정, σ 쓰임새를 오차 비로 표시, 2×2 라벨 실험, 출처·수정 로그, 유의하지 않은 결과도 그대로 보고.

**허점 (피할 것 / 질문 포인트)**:
- 기준값 흔들림: '1차 설정'이 random 29.10–29.3, scaffold 35.77–36.7 (흔들림 0.9 K > 열 효과 0.65 K). 튜닝 모델도 26.4/35.3(18쪽) vs 26.20/34.70(24쪽). 데이터 버전·seed 표기 없음.
- CI는 열 효과와 구간 잔차에만 있고, CI가 test 표본 변동만인지 seed까지인지 불명. 2부 실험 7개가 같은 test를 쓰고 '최저'도 test로 고름.
- 결론 1(데이터 양)은 직접 실험이 없음(학습 곡선 없음). 결론 3(성능과 해석이 함께 좋아짐)은 튜닝 모델에서 유의하지 않음.
- 23쪽 순위 해석이 10쪽 자기 규칙(상위 3개만 해석)과 충돌. 수소결합 짝은 HBD·HBA에서 만든 열이라 중요도를 나눠 가짐. 한 열씩 빼보는 실험이 없음.
- '나무 수 효과'는 1차 설정(500그루 × lr 0.03)이 덜 학습된 것. 후보 5개가 모두 600그루 이하. scaffold를 개선한 '다른 설정'은 미기재.
- 크기 분석: MP와 섞여 있음(큰 분자 = 고융점 = 평균 당김이 큰 구간). 무거운 원자 10개 이하 구간도 오차가 큼(U자) → '데이터 부족'만으로는 설명 안 됨. 가중치 비교는 >45 구간 random test가 약 10개인데 CI 없음.
- 식 방식: 손실이 ΔHm 척도 → 유연한(ΔSm 큰) 분자에 가중이 쏠리고, 강직한(ΔSm 작은) 분자는 Tm 오차가 커짐 → scaffold가 나빠진 유력한 원인(확인 필요).
